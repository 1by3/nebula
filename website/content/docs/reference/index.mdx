Use this reference to look up a public C# type or member. For instructions and complete examples, start with the [guides](/docs/guides/network-behaviour).

## Core

Build replicated gameplay with identities, behaviors, variables, RPCs, prediction, sync components, and project settings.

| Type | Summary |
| --- | --- |
| [AuthorityMode](/docs/reference/core/authority-mode) | Enum. Lists which process produces state for a synchronized component. |
| [AuthorityRpcAttribute](/docs/reference/core/authority-rpc-attribute) | Class. Runs on the worker that has authority over the entity. |
| [ClientRpcAttribute](/docs/reference/core/client-rpc-attribute) | Class. Runs on every client that knows the entity (or only its owner when sent with OwnerRpc). |
| [CommandLine](/docs/reference/core/command-line) | Static class. Tiny "-key value" / "-flag" parser over Environment.GetCommandLineArgs. |
| [INetworkInput](/docs/reference/core/i-network-input) | Interface. Marker for the per-tick input struct a predicted entity consumes. |
| [IRpcSink](/docs/reference/core/i-rpc-sink) | Interface. Where RPCs and state changes go once a behaviour has produced them. |
| [NebulaConfig](/docs/reference/core/nebula-config) | Class. Project-wide Nebula settings. |
| [NebulaGameMode](/docs/reference/core/nebula-game-mode) | Abstract class. Server-side game hooks, the equivalent of subclassing Mirror's NetworkManager. |
| [NebulaLog](/docs/reference/core/nebula-log) | Static class. Thin logging wrapper so every Nebula line is greppable by prefix in headless logs. |
| [NebulaRuntime](/docs/reference/core/nebula-runtime) | Static class. Process-wide role context. |
| [NetworkAnimator](/docs/reference/core/network-animator) | Class. Replicates selected Animator parameters from the authoritative worker to clients and ghost workers. |
| [NetworkBehaviour](/docs/reference/core/network-behaviour) | Abstract class. Base class for replicated gameplay components. |
| [NetworkIdentity](/docs/reference/core/network-identity) | Class. Marks a GameObject as a networked entity. |
| [NetworkPrefabs](/docs/reference/core/network-prefabs) | Static class. Prefab id table shared by every process. |
| [NetworkRigidbody](/docs/reference/core/network-rigidbody) | Class. Puts a Unity Rigidbody under the mesh's authority model. |
| [NetworkSyncBehaviour](/docs/reference/core/network-sync-behaviour) | Abstract class. Base for components that replicate through the per-tick sync channel and support server or owner authority. |
| [NetworkTime](/docs/reference/core/network-time) | Static class. Provides the shared 60 Hz simulation tick. |
| [NetworkTransform](/docs/reference/core/network-transform) | Class. Replicates selected position, rotation, and scale axes from the authoritative worker to clients and ghost workers. |
| [NetworkVariable\<T\>](/docs/reference/core/network-variable) | Class. A field replicated from the authoritative worker to clients and ghost workers. |
| [NetworkVariableBase](/docs/reference/core/network-variable-base) | Abstract class. Defines the serialization and change tracking used by every NetworkVariable\<T\>. |
| [PredictedBehaviour\<TInput\>](/docs/reference/core/predicted-behaviour) | Abstract class. A server-authoritative, client-predicted behaviour (the player controller, typically). |
| [PredictedBehaviourBase](/docs/reference/core/predicted-behaviour-base) | Abstract class. Non-generic surface Nebula's worker and client drive; game code derives from PredictedBehaviour\<TInput\>. |
| [RemoteInterpolator](/docs/reference/core/remote-interpolator) | Class. Tick-indexed pose buffer for copies of an entity this process does not simulate: ghosts on a worker and remote entities on a client. |
| [SceneEntities](/docs/reference/core/scene-entities) | Static class. The scene-placed entities resident in this process, by NetworkIdentity.SceneId. |
| [ServerRpcAttribute](/docs/reference/core/server-rpc-attribute) | Class. Sent by the owning client, runs on whichever worker currently has authority over the entity. |
| [SyncStateCodec](/docs/reference/core/sync-state-codec) | Static class. Envelope shared by the per-tick sync stream (EntityState/GhostSyncState messages) and the spawn snapshot: \[count\]\{\[behaviourIndex\]\[flags\]\[len:ushort\]\[chunk\]\}. |
