One party's link through a [`Portal`](/docs/reference/containers/portal) (`docs/portals.md` D8, D9): the far scope, the state the link is in and, when it is not open, what it waits for. Created by [`Portal.Open`](/docs/reference/containers/portal#open); the worker that owns the portal drives it Closed → Preparing → Open → Closing → Closed. Read it from the worker that owns the portal.
