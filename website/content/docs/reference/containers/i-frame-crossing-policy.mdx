```csharp
public interface IFrameCrossingPolicy
```

The game's say over where entities may cross a physics frame's boundary: anywhere on the hull, or only through portals. Asked on the worker that performs the crossing (the frame's pose owner, D15), once per tick while the entity wants to cross. Install one on [`PhysicsFrames.CrossingPolicy`](/docs/reference/containers/physics-frames#crossingpolicy).
