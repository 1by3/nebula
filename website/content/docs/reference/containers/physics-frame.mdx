A container's own physics frame: a local physics scene in which the container stands still (`docs/container-tree.md` §3). Everything the container holds is parented under [`Root`](#root), so in simulation space (every worker, and a client while it predicts) positions inside the frame are container-local and "down" is the container's own down.

### Origin [#origin]

```csharp
public Vector3 Origin { get; }
```

The frame's floating origin (`docs/container-tree.md` D19): the frame-local point that sits at Unity's origin in simulation space. Zero until the worker moves it with [`PhysicsFrames.ShiftOrigin`](/docs/reference/containers/physics-frames#shiftorigin); a planet's frame is large, and physics a few thousand kilometres from Unity's origin would be imprecise.
