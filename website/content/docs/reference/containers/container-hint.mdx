What the game knows about a container that the orchestrator cannot measure: how expensive it really is, what it belongs with, how much a worker boundary beside it hurts, and whether it wants a machine to itself. The built-in [`CostBalancedAssignmentPolicy`](/docs/reference/orchestrator/cost-balanced-assignment-policy) reads these; a game with needs beyond them writes its own [`IAssignmentPolicy`](/docs/reference/orchestrator/i-assignment-policy).

A hint is set at bake time on [`WorldContainerManifest.Entry`](/docs/reference/world/world-container-manifest#entry) (the World window edits it per cell) and at runtime through [`IControlPlane.SetContainerHint`](/docs/reference/control-plane/i-control-plane#setcontainerhint), which stores it beside the lease so an orchestrator restart sees it again. The runtime value wins over the baked one.

## Fields

### CostMultiplier [#costmultiplier]

```csharp
public float CostMultiplier;
```

Scales what this container is treated as costing: 1 is "as measured", 2 makes the planner give it twice the room. The manual correction for a container whose occupancy is a poor proxy for its tick time - a handful of entities running expensive AI, or a hundred static props that cost almost nothing.

### AffinityGroup [#affinitygroup]

```csharp
public string AffinityGroup;
```

Containers sharing a non-empty group are dealt as one item, so an instanced dungeon's rooms land on the same worker and nobody crosses a machine boundary walking through a door. "" means no group.

### SeamCost [#seamcost]

```csharp
public float SeamCost;
```

0..1: how much a worker boundary next to this container hurts. Where two neighbours on the curve both carry it, the planner charges itself for cutting between them and prefers to cut somewhere else. Raise it on whatever is currently hot and contested (the cells inside a battle royale's circle).

### Dedicated [#dedicated]

```csharp
public bool Dedicated;
```

This container wants a worker to itself: the planner reserves one for it before dealing everything else. A city hub, a raid boss room. A worker holding one is never chosen for retirement.

### EffectiveMultiplier [#effectivemultiplier]

The multiplier as the planner uses it: a hint that was never initialised (a zeroed struct out of a list) means "as measured", not "free", so anything at or below zero reads as 1.

The compact string form used on a command line and in the CLI: `x2,group=keep,seam=0.5,dedicated`. Only the parts that differ from the default are written, so a default hint is "".

Read the form [`ToString`](#tostring) writes. Unknown parts are ignored, so a newer hint field passing through an older build is dropped rather than rejected; "" is the default hint.
