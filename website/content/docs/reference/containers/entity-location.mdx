Where an entity durably is, independent of which worker holds it: an opaque scope key, a container id and a pose in that container's local space. A [`NetworkIdentity`](/docs/reference/core/network-identity) reports its current location as [`NetworkIdentity.Location`](/docs/reference/core/network-identity#location) and a [`PersistedEntityRecord`](/docs/reference/persistence/persisted-entity-record) its saved one as [`PersistedEntityRecord.Location`](/docs/reference/persistence/persisted-entity-record#location); both are this type, and two processes given the same value resolve the same container ([`Resolve`](#resolve)).

The scope key is the string the game chose for the entity's simulation scope: [`PublicScope`](#publicscope) (empty) for the public world, or the instance key (`TemplateId/key`, as passed to [`NebulaWorker.PrepareInstance`](/docs/reference/worker/nebula-worker#prepareinstance)) for a private instance. Nebula never parses or interprets it; it only compares it with ordinal string equality. The container id is the container's string id ([`Container.ContainerId`](/docs/reference/containers/container#containerid)), whose form tells the kind ([`ContainerKind`](#containerkind)). Equality is exact: ordinal on the strings and per component on the pose, never approximate.

The value does not carry the authority epoch, the owning worker or the wire index of the container, which are the parts of an entity's placement that change on a handover, a lease change or a rebuild. The design of record is `docs/location-contract.md`.

### Resolve [#resolve]

```csharp
public Container Resolve();
```

The container this location names in this process, or null when there is none here. The lookup is by [`ContainerId`](#containerid) in [`ContainerRegistry`](/docs/reference/containers/container-registry), which every role (worker, client, gateway, orchestrator) fills from the same scene, manifest and lease rows; a container found under the id but belonging to another scope ([`Container.ScopeKey`](/docs/reference/containers/container#scopekey) differs from [`ScopeKey`](#scopekey)) is not returned. Null also when the container has not arrived yet: a dynamic container arrives with its carrier, a runtime container with its lease.
