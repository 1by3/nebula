Defines a box-shaped authority area with its own local coordinate space. Nebula parents contained entities under its transform and replicates their local positions. The orchestrator assigns a static container from a scene or world manifest to a worker.

A container on the root of an entity (next to its [`NetworkIdentity`](/docs/reference/core/network-identity)) is carried by that entity: a ship's interior, a lift, a train car ([`FrameMode`](#framemode) is [`ContainerFrameMode.Entity`](/docs/reference/containers/container-frame-mode#entity)). It registers when the entity spawns on a process and unregisters when it despawns there, moves with the entity's root transform, and normally follows the entity's authoritative worker. Reach it through [`NetworkIdentity.Carried`](/docs/reference/core/network-identity#carried). The entity needs a [`NetworkTransform`](/docs/reference/core/network-transform) on its root; a container on a child object of an entity is not supported.

Nebula uses [`NebulaConfig.GhostBandMargin`](/docs/reference/core/nebula-config#ghostbandmargin) to send nearby entities to a neighboring worker before they cross the boundary. It uses [`NebulaConfig.HandoverHysteresis`](/docs/reference/core/nebula-config#handoverhysteresis) to prevent an entity near a boundary from repeatedly changing workers.

### NestingDepth [#nestingdepth]

```csharp
public int NestingDepth { get; }
```

How many carriers this container sits inside, walking up through [`Enclosing`](#enclosing): 0 for a static container, 1 for a ship in a static container, 2 for a shuttle inside that ship. There is no depth limit. This is what orders simulation and the ghost band, and two containers at different depths reported as equal would let a passenger tick before the ship it stands in. The walk cannot run away: every dynamic container is registered, so a chain longer than the registry has closed a cycle. That is the only bound; a cycle cannot be built in the first place (see [`IsCarriedBy`](#iscarriedby)).

### IsCarriedBy [#iscarriedby]

```csharp
public bool IsCarriedBy(NetworkIdentity entity);
```

Whether `entity` carries this container, directly or through a chain of carriers: this is `entity`'s own box, or a box riding somewhere inside it (a shuttle parked in its hangar, a crate's box in that shuttle). Putting `entity` in such a container would make it ride inside itself; [`ContainerRegistry.Find`](/docs/reference/containers/container-registry#find) skips these containers for the entity and the entity refuses to be placed in one. A chain longer than the registry holds has already looped and also answers true, so nothing is ever added to it.

### SignedDistance [#signeddistance]

```csharp
public float SignedDistance(Vector3 worldPosition);
```

Signed distance to the box surface: positive outside (how far, in any direction), negative inside (how deep, measured to the nearest *wall* only). The floor and ceiling do not count as depth: pawns stand on the floor, which is the bottom face of the box, and treating it as a seam would keep every entity in a room permanently "about to leave" for the ghost band and never past the handover hysteresis.

### DistanceToSeam [#distancetoseam]

```csharp
public float DistanceToSeam(Vector3 worldPosition, Container neighbor);
```

How far a point inside this container is from its seam with `neighbor`. For a sibling or an inner box that is the neighbor's surface; for a neighbor that encloses this one (a building inside the outdoor area, the area around a ship) the seam is this container's own surface, so the answer is how far the point is from getting out - not "inside the enclosing box", which would put every entity in every building in the band permanently.

### IntersectsSegment [#intersectssegment]

```csharp
public bool IntersectsSegment(Vector3 a, Vector3 b, float margin, out float tEnter, out float tExit);
```

Whether the segment from `a` to `b` passes through the box grown by `margin` on every side, and where along it (`tEnter` and `tExit` are fractions of the segment, clamped to \[0, 1\]). A segment starting inside the box enters at 0. Slab test in the container's local space, so rotated boxes are exact. The margin absorbs handover hysteresis and an entity's own radius when the caller asks "whose entities could this ray touch".

### PlacementProblem [#placementproblem]

```csharp
public static string PlacementProblem(Container c, out bool error);
```

Where a container sits decides what it is ([`FrameMode`](#framemode)); say so when the placement cannot work. A box on a child object of an entity is baked as a fixed container, so it would never move with the entity; a box on an entity's root needs a root [`NetworkTransform`](/docs/reference/core/network-transform), because every process positions the contents from the carrier's replicated pose. The Nebula validator reports the same.

**Returns:** Null when the placement works; otherwise the problem, with `error` set when the container cannot work at all.
