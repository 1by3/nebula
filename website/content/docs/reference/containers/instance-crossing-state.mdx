The state of one entity's crossing through an [`InstanceBoundary`](/docs/reference/containers/instance-boundary), as [`InstanceBoundary.TryGetPreparation`](/docs/reference/containers/instance-boundary#trygetpreparation) and [`InstanceBoundary.CrossingReady`](/docs/reference/containers/instance-boundary#crossingready) report it.

A ready crossing is not a reservation: the commit still checks admission, the entity's authority and the destination's lease, as [`NebulaWorker.TryCommitTransfer`](/docs/reference/worker/nebula-worker#trycommittransfer) does.
