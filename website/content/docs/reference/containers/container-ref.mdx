How a container is named on the wire. A static container (authored into the scene or baked into the world manifest) is its dense registry [`Index`](#index), identical in every process. A dynamic container (one a [`DynamicContainer`](/docs/reference/containers/dynamic-container) entity carries: a ship, a train, a moving station) has no stable index, since it is created and destroyed at runtime by whichever worker spawns its carrier; it is named by the carrier's [`NetId`](#netid), which is already mesh-unique and follows the entity through every handover. On the wire that is two bytes for a static container and ten for a dynamic one.
