### Prepare [#prepare]

```csharp
public static bool Prepare(Container container);
```

Load this container's geometry. Returns false when its resource is missing or contains network identities.

True means the content was created, not that it has finished loading: content with an [`IInstanceContentLoader`](/docs/reference/containers/i-instance-content-loader) may still be building. [`ContentState`](#contentstate) reports that.

### ContentState [#contentstate]

```csharp
public static InstanceContentState ContentState(Container container);
```

Whether a prepared container's content has finished loading: [`InstanceContentState.Failed`](/docs/reference/containers/instance-content-state#failed) when any [`IInstanceContentLoader`](/docs/reference/containers/i-instance-content-loader) under it has failed, [`InstanceContentState.Loading`](/docs/reference/containers/instance-content-state#loading) while any is still loading, and [`InstanceContentState.Ready`](/docs/reference/containers/instance-content-state#ready) otherwise. Content with no loaders, a container in the public world, and a container that has not been prepared are [`InstanceContentState.Ready`](/docs/reference/containers/instance-content-state#ready). A child or carried container reports the content that [`Prepare`](#prepare) loads for it.

### KeepDrawn [#keepdrawn]

```csharp
public static void KeepDrawn(ulong instanceId);
```

Keep a scope's content drawn on this client while the local pawn is in another scope: the static content [`Prepare`](#prepare) loads for its instance parts, and the content under the `World.ChunkContext.Root` of its scoped grid's chunks. A client normally draws only the pawn's own scope and the public world, and keeps other resident scopes hidden; use this to show the other side of an open doorway. Content created or loaded while the request is live starts drawn.

Requests are counted: match each call with one [`StopKeepingDrawn`](#stopkeepingdrawn). The scope is hidden again only when its last request is withdrawn. Nebula turns on only the renderers it turned off itself, so renderers the game turned off stay off. A request outlives the scope's content: when the content is released Nebula forgets its renderers but keeps the request, so content of the scope prepared again starts drawn.

Rendering only. It loads nothing, and changes no physics scene, interest, ownership or message: content that is not resident on this client stays absent. A worker records the request and ignores it. The public world (`instanceId` 0) is always drawn, so a request for it does nothing.

| Parameter | Description |
| --- | --- |
| `instanceId` | The scope's instance ID, as [`Container.InstanceId`](/docs/reference/containers/container#instanceid) reports it. |

### StopKeepingDrawn [#stopkeepingdrawn]

```csharp
public static bool StopKeepingDrawn(ulong instanceId);
```

Withdraw one [`KeepDrawn`](#keepdrawn) request for a scope. When it was the last one and the local pawn is in another scope, the scope's content is hidden again. Returns false, and changes nothing, when the scope has no request.

| Parameter | Description |
| --- | --- |
| `instanceId` | The scope's instance ID passed to [`KeepDrawn`](#keepdrawn). |

### IsDrawn [#isdrawn]

```csharp
public static bool IsDrawn(ulong instanceId);
```

Whether a scope's content is drawn on this client: true for the public world, for the local pawn's scope, and for a scope with a live [`KeepDrawn`](#keepdrawn) request; false for any other scope. Always true on a process that is not a client, which hides nothing.

| Parameter | Description |
| --- | --- |
| `instanceId` | A scope's instance ID; 0 is the public world. |
