Whether an instance part's content is still loading, ready, or failed. [`IInstanceContentLoader.State`](/docs/reference/containers/i-instance-content-loader#state) reports it.

## Members

| Name | Value | Description |
| --- | --- | --- |
| <span id="loading"></span>`Loading` |  | The content is still being built or loaded. A crossing into it waits. |
| <span id="ready"></span>`Ready` |  | The content is complete. A crossing into it can be acknowledged. |
| <span id="failed"></span>`Failed` |  | The content cannot be completed. A crossing into it is refused, as for a missing content resource. |
