Obsolete, and does nothing. A [`Container`](/docs/reference/containers/container) on an entity's root, next to its [`NetworkIdentity`](/docs/reference/core/network-identity), is carried by that entity on its own now ([`Container.FrameMode`](/docs/reference/containers/container#framemode) is [`ContainerFrameMode.Entity`](/docs/reference/containers/container-frame-mode#entity)): it registers when the entity spawns and unregisters when it despawns, and [`NetworkIdentity.Carried`](/docs/reference/core/network-identity#carried) reaches it. Remove this component with **Nebula \> Migrate \> Remove DynamicContainer**, which strips it from every prefab and open scene. It is kept for one release so projects still load, and is no longer a [`NetworkBehaviour`](/docs/reference/core/network-behaviour), so it takes no behaviour slot on the entity.
