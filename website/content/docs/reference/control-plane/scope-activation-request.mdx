### PreferredWorkerId [#preferredworkerid]

```csharp
public string PreferredWorkerId = "";
```

Create the lease rows already assigned to this worker, so the worker that asked owns them from the first change anyone sees (this is what [`NebulaWorker.PrepareInstance`](/docs/reference/worker/nebula-worker#prepareinstance) has always done). Empty when the caller is not a worker: the rows are born orphaned and the orchestrator deals them out.
