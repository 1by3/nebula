The control plane as the orchestrator hosts it: a [`LocalControlPlane`](/docs/reference/control-plane/local-control-plane) that is the source of truth, served to workers and gateways over the orchestrator's HTTP server and kept in an [`IControlPlaneStorage`](/docs/reference/control-plane/i-control-plane-storage) between runs.

- `GET /api/control-plane?since=<version>&wait=<seconds>` answers with the current document ([`ControlPlaneJson`](/docs/reference/control-plane/control-plane-json)) as soon as its version is above `since`, or when `wait` seconds pass. Subscribers ([`RemoteControlPlane`](/docs/reference/control-plane/remote-control-plane)) keep one such request open.
- `POST /api/control-plane` with `{"ops":[...]}` applies writes in order on the main thread (through [`TryHandle`](#tryhandle), from the orchestrator's command pump), so the orchestrator sees them in the same tick it would see its own.

With a mesh token every request carries it in the `X-Nebula-Token` header; without one the API is open, which is fine on a private network or a development machine. Reads are answered on the listener thread from the last published document, so the orchestrator's main thread never waits on a subscriber.

## Constructors

### ControlPlaneHost [#controlplanehost]

```csharp
public ControlPlaneHost(IControlPlaneStorage storage, string token, bool restore = true);
```

| Parameter | Description |
| --- | --- |
| `storage` | Where the document is kept between runs; null keeps it in memory only. |
| `token` | Shared secret subscribers must present; null or empty for none. |
| `restore` | Read the stored document at [`Connect`](#connect). The orchestrator resets the plane at its first tick unless `-nebula-reset false`, so this only matters then. |
