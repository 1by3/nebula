In-process control plane with the exact semantics of the SpacetimeDB module (see Module~/Lib.cs), for single-process runs and tests. Changes are applied synchronously and [`Changed`](#changed) fires on the next [`Tick`](#tick), mirroring the subscription push of the real thing.
