The control plane's state machine: registrations, heartbeats, leases with epochs and settings, kept in plain lists in this process. Changes are applied synchronously and [`Changed`](#changed) fires on the next [`Tick`](#tick). On its own it serves single-process runs and tests; [`ControlPlaneHost`](/docs/reference/control-plane/control-plane-host) wraps it on the orchestrator, where it is the source of truth every [`RemoteControlPlane`](/docs/reference/control-plane/remote-control-plane) mirrors.

### ActivateScope [#activatescope]

```csharp
public void ActivateScope(ScopeActivationRequest request);
```

Make the scope named by `request` exist, or leave the one that already exists alone. Called on the orchestrator's main thread, which serialises it against every other control-plane write, so the check and the create are one step; the durable claim ([`IScopeStore`](/docs/reference/control-plane/i-scope-store)) makes the same hold across orchestrator runs.
