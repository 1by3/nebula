```csharp
public struct GatewayStats
```

What a gateway reports about itself on every heartbeat. The orchestrator publishes it in `/api/state`; whoever runs the gateway fleet (a hosting platform, an operator) sizes the fleet from these numbers, since a connection count alone says nothing about replication cost.

## Fields

### PendingJoins [#pendingjoins]

```csharp
public uint PendingJoins;
```

Clients welcomed by this gateway that are still waiting for somewhere to spawn ([`JoinState.Starting`](/docs/reference/protocol/join-state#starting)). The orchestrator reads it as demand: a pending join at zero workers wakes the mesh at once, and no scale-in goes below one worker while it is non-zero.
