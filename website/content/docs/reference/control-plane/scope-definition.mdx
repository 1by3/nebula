What a scope is made of: the containers to bring into being and how their occupants see the public world. A definition is compared by value (its canonical JSON), so activating the same key twice with the same definition is a no-op and activating it with a different one is refused rather than silently merged.

[`Kind`](#kind) and [`Payload`](#payload) are the extension seam: scoped chunk grids (NEB-239) add a kind of their own and put the grid definition in the payload. Nebula carries the payload verbatim and never parses it.
