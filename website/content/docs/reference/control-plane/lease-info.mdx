### Authority [#authority]

```csharp
public ContainerAuthority Authority;
```

Who simulates what is inside. On a runtime row [`ContainerAuthority.Inherited`](/docs/reference/containers/container-authority#inherited) means the row only carries the box: the orchestrator never deals it and nobody reads an owner from it. On a carried container's row (`label#netId`) [`ContainerAuthority.Leased`](/docs/reference/containers/container-authority#leased) means the container was authored leased: the orchestrator re-deals it instead of letting it follow its carrier.

### HasHint [#hashint]

```csharp
public bool HasHint;
```

A balancing hint was set for this container while the mesh runs ([`IControlPlane.SetContainerHint`](/docs/reference/control-plane/i-control-plane#setcontainerhint)). It travels beside the lease and is stored with it, so an orchestrator that restarts sees it again; when false the baked hint ([`Container.Hint`](/docs/reference/containers/container#hint)) stands.

### HasCapacity [#hascapacity]

```csharp
public bool HasCapacity;
```

The orchestrator has published a capacity reading for this container ([`IControlPlane.SetContainerCapacity`](/docs/reference/control-plane/i-control-plane#setcontainercapacity), docs/capacity-admission.md). False means no worker has reported cost for it lately, and an unknown container is never at capacity.
