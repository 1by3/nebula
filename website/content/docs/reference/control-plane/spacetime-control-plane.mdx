[`IControlPlane`](/docs/reference/control-plane/i-control-plane) over the SpacetimeDB module in Assets/Nebula/SpacetimeDB/Module~. Subscribes to the whole (tiny) database and mirrors it into plain lists; writes go through reducers. The connection is pumped from [`Tick`](#tick) so every callback lands on the main thread.
