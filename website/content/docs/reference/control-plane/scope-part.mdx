One runtime container of a scope: a stable part id and an axis-aligned box in absolute world coordinates.

## Fields

### PartId [#partid]

```csharp
public string PartId = "";
```

Non-empty and unique within the definition. It is hashed with the scope key into the container id, so changing it renames the place.

### Center [#center]

```csharp
public Double3 Center;
```

Box centre, in the same absolute frame as [`LeaseInfo.Center`](/docs/reference/control-plane/lease-info#center) (see `docs/scope-activation.md` D4), in double, so a part 100,000 km from the absolute origin is placed to the millimetre. A `Vector3` converts implicitly.

### Size [#size]

```csharp
public Vector3 Size;
```

Box size; every component must be positive.

### ContentResource [#contentresource]

```csharp
public string ContentResource = "";
```

Resources path of this part's static geometry, or empty. Loaded by the worker that owns the lease, through the game's existing instance-content path.
