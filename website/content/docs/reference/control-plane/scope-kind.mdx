### Grid [#grid]

```csharp
public const string Grid = "grid";
```

A procedural chunk grid (`docs/scoped-chunk-grids.md`): the payload is a [`ChunkGridDefinition`](/docs/reference/world/chunk-grid-definition) and the parts are the anchor chunk alone, so activating a world does not enumerate its chunks. Every other chunk of the scope is leased on demand, under an id derived from the same key ([`ChunkKeys.RuntimeId`](/docs/reference/world/chunk-keys#runtimeid)).
