The control plane as one JSON document, and one control-plane write as one JSON object. This is the wire format between [`RemoteControlPlane`](/docs/reference/control-plane/remote-control-plane) (workers, gateways) and [`ControlPlaneHost`](/docs/reference/control-plane/control-plane-host) (the orchestrator), and the format the host stores through [`IControlPlaneStorage`](/docs/reference/control-plane/i-control-plane-storage).

Snapshot: `{"version":N,"now":unixMs,"workers":[...],"leases":[...],"gateways":[...],"settings":{...}}`. Write: `{"op":"RegisterWorker","workerId":"w1",...}`; a request carries a list of them under `"ops"`, applied in order. Times are Unix milliseconds; vectors are `[x, y, z]`.
