### HasGlobalEntities [#hasglobalentities]

```csharp
public bool HasGlobalEntities;
```

This worker holds at least one always-relevant entity. A gateway keeps a link to such a worker even when it subscribes no region there, because a global entity belongs in every client's set and nothing else would make the gateway ask for it.

### OldestDirtySeconds [#oldestdirtyseconds]

```csharp
public float OldestDirtySeconds;
```

[`NebulaPersistence.OldestDirtyAgeSeconds`](/docs/reference/persistence/nebula-persistence#oldestdirtyageseconds) on this worker, or 0 when persistence is off. An additive field on the existing heartbeat message: older orchestrators simply do not read it.
