[`IControlPlane`](/docs/reference/control-plane/i-control-plane) for a worker or gateway: a mirror of the control plane the orchestrator hosts ([`ControlPlaneHost`](/docs/reference/control-plane/control-plane-host)), reached over HTTP at the orchestrator's dashboard address.

A reader thread keeps one long-poll request open (`GET /api/control-plane?since=<version>`) and parses each document it gets; [`Tick`](#tick) swaps the parsed lists in on the main thread and raises [`Changed`](#changed), so callers see the same threading as with any other control plane. Writes are queued and a sender thread posts them in order, batched when several are waiting; a write is never dropped while the orchestrator is unreachable, only delayed (up to [`MaxQueuedWrites`](#maxqueuedwrites), after which the oldest go). [`Now`](#now) is the orchestrator's clock as of the last document plus the time since.
