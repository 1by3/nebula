A shared simulation scope the mesh has been asked to bring into being: the opaque key that names it, the definition it was activated from, and the containers that now exist for it. One row per key, mirrored to every worker, gateway and orchestrator in the control-plane document.

## Fields

### ScopeKey [#scopekey]

```csharp
public string ScopeKey = "";
```

The opaque key. Never empty (the public world is [`EntityLocation.PublicScope`](/docs/reference/containers/entity-location#publicscope) and is never activated).

### InstanceId [#instanceid]

```csharp
public ulong InstanceId;
```

The scope's 64-bit isolation id ([`ScopeKeys.Hash`](/docs/reference/control-plane/scope-keys#hash)), the same value entities carry in [`NetworkIdentity.InstanceId`](/docs/reference/core/network-identity#instanceid).

### State [#state]

```csharp
public string State = ScopeState.Active;
```

See [`ScopeState`](/docs/reference/control-plane/scope-state).

### ContainerIds [#containerids]

```csharp
public List<string> ContainerIds = new List<string>();
```

The scope's container ids, in definition order ([`ScopeKeys.ContainerId`](/docs/reference/control-plane/scope-keys#containerid)).

### Definition [#definition]

```csharp
public ScopeDefinition Definition = new ScopeDefinition();
```

The definition the first activation won with. A later activation with a different one is refused.

### CreatedAt, UpdatedAt [#createdat-updatedat]

```csharp
public DateTime CreatedAt, UpdatedAt;
```

When the row was created, and when it was last activated. NEB-240 aggregates idle age over these rows.

### Requester [#requester]

```csharp
public string Requester = "";
```

Who last asked for it, for logs and the dashboard. Free-form; Nebula attaches no meaning to it.
