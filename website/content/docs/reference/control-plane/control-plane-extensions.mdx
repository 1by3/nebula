### IsScopeReady [#isscopeready]

```csharp
public static bool IsScopeReady(this IControlPlane cp, ScopeInfo scope, float workerTimeoutSeconds = 15f);
public static bool IsScopeReady(this IControlPlane cp, string scopeKey, float workerTimeoutSeconds = 15f);
```

Whether the scope can be entered: every container of it has a lease row in an owning state ([`LeaseState.IsOwning`](/docs/reference/control-plane/lease-state#isowning)) held by a worker that is still heartbeating. It does **not** say that the worker has loaded the scope's content — that stays with the per-crossing handshake ([`NebulaWorker.PrepareTransfer`](/docs/reference/worker/nebula-worker#preparetransfer)). See `docs/scope-activation.md` §4.
