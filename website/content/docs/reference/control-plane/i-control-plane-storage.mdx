Where [`ControlPlaneHost`](/docs/reference/control-plane/control-plane-host) keeps the control plane between orchestrator runs: one JSON document ([`ControlPlaneJson`](/docs/reference/control-plane/control-plane-json)), written a little after every change and read once at startup. The document is small and changes at most a few times a second, so the contract is whole-document replace. A store that throws is logged and retried on the next change; the mesh keeps running on the in-memory state.
