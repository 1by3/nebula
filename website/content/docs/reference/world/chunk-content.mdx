Scene-object form of [`NebulaChunks.Loaded`](/docs/reference/world/nebula-chunks#loaded)/[`NebulaChunks.Unloading`](/docs/reference/world/nebula-chunks#unloading): drop a subclass in the game scene and override [`OnChunkLoaded`](#onchunkloaded). It exists because a chunk generator is usually authored content — a prefab list, a material, a noise setting — and a `MonoBehaviour` is where a Unity developer expects to put those, whereas the static events are what a headless service or a test wants. Both paths are the same events; use whichever reads better.

Subscription happens in `OnEnable`, and [`NebulaChunks.Loaded`](/docs/reference/world/nebula-chunks#loaded) back-fills, so a component enabled long after the first chunks arrived still builds all of them.
