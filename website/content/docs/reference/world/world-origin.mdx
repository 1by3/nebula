The floating origin: which cell currently sits at Unity's (0,0,0). Every position a process handles is expressed in this frame (a "frame position"). When the frame moves, [`Shifted`](#shifted) reports the delta to add to every frame position the streamer did not move itself (cached positions, history buffers, world-space particle systems...).
