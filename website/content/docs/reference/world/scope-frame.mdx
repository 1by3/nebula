One scope's floating origin: which cell of *that scope's* grid currently sits at Unity's (0,0,0), and the delta every frame position of that scope gets when it moves. The public world's frame is [`ScopeFrames.Public`](/docs/reference/world/scope-frames#public), which is [`WorldOrigin`](/docs/reference/world/world-origin) itself, so a project with no scopes behaves exactly as it always did.

A worker may hold containers of many scopes whose coordinates have nothing to do with each other. Each of them keeps its own origin cell, so two scopes can both sit near Unity's origin on one worker without interfering: they are already in separate physics scenes (`InstanceScenes`) and separate container graphs. Design record: `docs/scope-frames.md`.
