A world partitioned into a 3D grid of cells, each authored as its own additive scene. Cells are authored **cell-local**: everything in a cell scene sits around that scene's own origin, and at runtime the [`WorldStreamer`](/docs/reference/world/world-streamer) places the cell at its grid position relative to the current [`WorldOrigin`](/docs/reference/world/world-origin). Nothing ever needs an absolute world coordinate, so a world can be far larger than float precision allows.

Cell `(x, y, z)` is centred on `(x, y, z) * CellSize`: cell (0,0,0) covers ±CellSize/2 on every axis, which is exactly how a scene authored around the origin already looks. A flat world is a single row of cells on Y; a world that shards verticality uses more.
