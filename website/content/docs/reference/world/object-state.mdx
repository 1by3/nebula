The saved state of one procedurally placed object: a rock that has been mined, a plant that has been harvested. An object with no entry is *untouched*, and the game draws it from its seed as it always would. Only objects that differ from that default have an entry (see [`ChunkState`](/docs/reference/world/chunk-state)).

[`Value`](#value) means whatever the game wants it to mean, such as units left or a growth stage. [`ExpiresAtUnixMs`](#expiresatunixms) is an absolute UTC time in Unix milliseconds. When that time passes, the entry is removed and the object is untouched again ("depleted until T"). Nothing runs while the object's chunk is unloaded: the time is compared when the chunk's state is next read or loaded.

### ExpiresAtUnixMs [#expiresatunixms]

```csharp
public readonly long ExpiresAtUnixMs;
```

When the entry reverts to untouched, in UTC Unix milliseconds. 0 means it never expires. Use [`ChunkState.NowUnixMs`](/docs/reference/world/chunk-state#nowunixms) to compute it, for example `ChunkState.NowUnixMs + 600_000` for ten minutes from now.
