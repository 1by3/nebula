Nebula's side of a partitioned world ([`WorldDefinition`](/docs/reference/world/world-definition) + [`WorldContainerManifest`](/docs/reference/world/world-container-manifest)): instantiates the manifest's container tree for the registry, owns the [`WorldStreamer`](/docs/reference/world/world-streamer), keeps the virtual containers and every entity's cached positions in step with origin shifts, and strips the authoring [`Container`](/docs/reference/containers/container) components out of cell scenes as they stream in. Inactive (everything behaves as a single scene) when [`NebulaConfig.WorldManifest`](/docs/reference/core/nebula-config#worldmanifest) is unset.
