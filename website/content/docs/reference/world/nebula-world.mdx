Nebula's floating-origin world state. A baked world ([`WorldDefinition`](/docs/reference/world/world-definition) + [`WorldContainerManifest`](/docs/reference/world/world-container-manifest)) instantiates the manifest's container tree, streams authored cell scenes, and strips their authoring [`Container`](/docs/reference/containers/container) components. A runtime world owns the same origin frame but leaves container registration and procedural content to the game. Both modes keep containers and every entity's cached positions in step with origin shifts. [`IsActive`](#isactive) specifically reports authored scene streaming.

### LoadRuntime [#loadruntime]

```csharp
public static void LoadRuntime(WorldDefinition definition);
```

Replace the current world with a procedural world that supports origin shifts without authored cell scenes. The game registers runtime containers and calls [`WorldStreamer.ShiftOrigin`](/docs/reference/world/world-streamer#shiftorigin) before local simulation. [`Definition`](#definition) returns this definition; [`IsActive`](#isactive) remains false because no authored scene loading is active. The definition must not be null.
