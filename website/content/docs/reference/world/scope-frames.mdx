public static class ScopeFrames

The origin frames this process holds, one per scope. The public world's frame always exists and is [`WorldOrigin`](/docs/reference/world/world-origin); a scope gets one the first time this process names it, which on a worker is the first time one of its containers turns up here (`docs/scoped-chunk-grids.md` D7).

A container or an entity whose scope has **no** frame here is in the public frame. A scoped chunk grid takes a frame of its own ([`Ensure`](#ensure)), and an instance scope (a room, a dungeon) a pinned one near its origin ([`Pin`](#pin), `docs/scope-frames.md` D11).

### Share [#share]

```csharp
public static void Share(ulong instanceId, ulong hostInstanceId);
```

Make an instance scope live in `hostInstanceId`'s frame (0: the public frame), and move with it, as every instance did before NEB-426. A client does this for an instance entered from a scope it is in, so the instance is drawn exactly where it is relative to that world (a doorway looks through to the right place, both ways) and a crossing does not move the pawn in Unity; the client keeps that frame's origin near its pawn, so it stays precise (`docs/scope-frames.md` D11). Ignored for a scope that already has or shares a frame.

### Ensure [#ensure]

```csharp
public static ScopeFrame Ensure(string scopeKey, ulong instanceId, Vector3 cellSize);
```

Give a scope a frame of its own, or return the one it has. The public world's is [`Public`](#public) and is never created here. The cell size is the scope's grid's; a later call with a different one updates it (a definition is validated once at activation, so this only ever refines a frame made from an inference).

### Pin [#pin]

```csharp
public static ScopeFrame Pin(string scopeKey, ulong instanceId, double x, double y, double z);
```

Give an instance scope (a room, a dungeon, an interior: anything that is not a scoped grid) a frame of its own, pinned so that the absolute point (`x`, `y`, `z`), in double, sits near Unity's origin, or return the frame it already has (`docs/scope-frames.md` D11). The pin is a cell of the public world's lattice (its cell size, or [`PinnedCellSize`](#pinnedcellsize) without a world definition), rounded to the nearest: so while this process's public origin is at that same cell, the instance's frame and the public one coincide exactly and nothing about where the instance appears relative to the public world changes. A pinned frame never shifts. Frames are local to a process, so a worker and a client may pin the same instance differently and still agree on every absolute coordinate (D4).
