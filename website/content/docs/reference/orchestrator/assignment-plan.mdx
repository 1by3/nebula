What a policy would do with a hypothetical number of workers: which containers each of them would hold, and how loaded that would leave them. The scaler compares the plan at N, N+1 and N-1 instead of guessing from an average ([`WorkerScaler`](/docs/reference/orchestrator/worker-scaler)).
