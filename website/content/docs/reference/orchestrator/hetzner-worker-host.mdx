One Hetzner Cloud VM per worker, created through the Hetzner Cloud API `(https://docs.hetzner.cloud).` Each VM boots Ubuntu with a cloud-init script that downloads the Linux server build from the orchestrator over the private network, reads its own private IP from the Hetzner metadata service, and starts the worker role as a systemd unit advertising that private IP. Killing a worker deletes its VM. On [`Initialize`](#initialize) every VM labelled with this mesh id is deleted, so a restarted orchestrator never inherits (and pays for) stale machines.

All HTTP work runs on the thread pool; results are queued and applied in [`Tick`](#tick) on the main thread, where the JSON is parsed with `JsonUtility`.

### BilledUntilSeconds [#billeduntilseconds]

```csharp
public static float BilledUntilSeconds(float launchedAt, float now, float billingPeriodSeconds = BillingPeriodSeconds);
```

End of the billing period a machine launched at `launchedAt` has been charged for as of `now`. Hetzner bills per started hour, so a machine up for five minutes is paid for until minute 60 and one up for 61 minutes until minute 120; keeping it parked until then is free. Pure function.

### RetainUntilSeconds [#retainuntilseconds]

```csharp
public static float RetainUntilSeconds(float launchedAt, float now, float idlePoolSeconds);
```

When a machine parked at `now` stops being kept: the end of the hour it has already been billed, or sooner when `idlePoolSeconds` asks for less. A longer idle pool is not honoured, because the hour after this one is a fresh charge and nobody asked to pay it.

[`BillingSafetyMarginSeconds`](#billingsafetymarginseconds) is taken off the *billed* deadline only, so the delete call lands before the next hour starts. It is not taken off a retention the developer asked for: an `IdlePoolSeconds` under the margin would otherwise mean "delete on the next tick".

Pure function; the result is the wall-clock moment the machine goes.

### Park [#park]

```csharp
public void Park(IWorkerHandle handle, float idlePoolSeconds);
```

Keep the machine instead of deleting it: the worker process stays up and keeps heartbeating, the orchestrator simply deals it nothing. It is deleted in [`Tick`](#tick) once the hour Hetzner has already charged for runs out (or sooner, when `idlePoolSeconds` is shorter), unless [`Unpark`](#unpark) claims it first.

Boot script for a worker VM. Waits for the private interface, fetches the build from the orchestrator, writes the game's variables (`env`) to [`WorkerEnvFile`](#workerenvfile) (root-only), and runs the worker as a systemd unit that reads it. `$PRIVATE_IP` in `workerArgs` expands on the machine; the variables are written literally.
