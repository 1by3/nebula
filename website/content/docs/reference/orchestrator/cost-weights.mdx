How much simulating a container costs a worker, from what is inside it. Players are the expensive ones (an input stream, prediction, interest management), bots less so, server-driven entities less again; every container costs [`Base`](#base) merely by being leased (its geometry, its scene entities, its ghosts). Ghosts are not counted: they are a consequence of the neighbours' load, not the container's own.

What this container costs. When the worker reported a per-entity cost sum ([`ContainerLoad.HasEntityCost`](/docs/reference/orchestrator/container-load#hasentitycost)) that sum is used: it is these same category weights with each entity's own multiplier applied ([`NebulaCost`](/docs/reference/core/nebula-cost)), so a world that sets no weights gets exactly the number the head count below gives. Otherwise the heads are counted here, as they always were.
