The planner's answer to "why is this still hot?". Emitted when the busiest worker's load cannot be reduced by moving anything it holds, and read by [`WorkerScaler`](/docs/reference/orchestrator/worker-scaler) (which names it in [`ScaleDecision.Reason`](/docs/reference/orchestrator/scale-decision#reason)), by the dashboard, and by admission reporting, which groups the rows by [`ScopeKey`](#scopekey). A report is a statement, never an action: Nebula does not split a container, and never breaks a group or a hold to relieve a worker (`docs/cohesion-rebalancing.md`, D5).
