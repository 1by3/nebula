Where a managed deployment's orchestrator asks for worker machines: a resource API scoped to this one deployment, reached with a token that can do nothing else. Read from `-nebula-cloud-api` and `-nebula-cloud-deployment-token`, with `NEBULA_CLOUD_API` and `NEBULA_CLOUD_DEPLOYMENT_TOKEN` as environment fallbacks (a systemd EnvironmentFile keeps the token off the command line).
