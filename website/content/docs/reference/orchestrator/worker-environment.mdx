The game's environment variables a worker host gives every worker it launches, in this order (a later layer wins over an earlier one):

1. The service manifest's `Env` map ([`ManifestEnv`](#manifestenv)): the non-secret variables of a self-hosted deployment, written by `nebula deploy` from `deploy.env` in nebula.json.
2. The dotenv file the host's own `NEBULA_ENV_FILE` names: secrets a platform keeps out of the build (Nebula Cloud), or the project's `.env.nebula` under `nebula start`.

Reserved names (`PORT`, `NEBULA_*`) are dropped with a warning; values are never logged.
