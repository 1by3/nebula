Where worker instances live. The orchestrator decides *how many* workers to run and which containers they own; a host decides *where* one runs and how to start and stop it. The reference host launches local child processes ([`ProcessWorkerHost`](/docs/reference/orchestrator/process-worker-host)); cloud hosts create one VM per worker ([`HetznerWorkerHost`](/docs/reference/orchestrator/hetzner-worker-host)). Liveness is judged from control-plane heartbeats regardless of host; the host's [`IWorkerHandle.State`](/docs/reference/orchestrator/i-worker-handle#state) only lets the orchestrator react sooner when a process exits or a machine disappears. Implementations must be safe to call every frame; slow work happens off the main thread and is surfaced from [`Tick`](#tick).

### SupportsParking [#supportsparking]

```csharp
bool SupportsParking { get; }
```

True when [`Park`](#park) is cheaper than [`Kill`](#kill) plus a fresh [`Launch`](#launch), so the orchestrator parks a retired worker into the idle pool instead of killing it. False on hosts where an instance costs nothing to recreate ([`ProcessWorkerHost`](/docs/reference/orchestrator/process-worker-host)) and on hosts written before parking existed ([`WorkerHostBase`](/docs/reference/orchestrator/worker-host-base) answers false), which keeps the old behaviour exactly.

### TypicalBootSeconds [#typicalbootseconds]

```csharp
float TypicalBootSeconds { get; }
```

Roughly how long this host takes to get a freshly launched worker simulating: the cost of a cold start, used for the scale-to-zero warning and for the dashboard's idle-pool copy. Process host ~3 s, a cloud VM that boots an image and downloads a build ~75 s.

Called once before the first launch. Hosts use it to look up cloud resources and to sweep leftovers from a previous orchestrator run (a crashed orchestrator must not leave paid machines behind).

### Kill [#kill]

void Kill(IWorkerHandle handle);

Stop the worker immediately (crash semantics: kill the process, delete the machine).

### Park [#park]

```csharp
void Park(IWorkerHandle handle, float idlePoolSeconds);
```

Retire the worker into the idle pool: the orchestrator has drained it and will deal it nothing more, but wants it back cheaply if load returns. A host that cannot park just kills the instance.

| Parameter | Description |
| --- | --- |
| `idlePoolSeconds` | How long the orchestrator would like it kept ([`NebulaConfig.IdlePoolSeconds`](/docs/reference/core/nebula-config#idlepoolseconds)); 0 means "as long as it is free", which is the host's own answer (Hetzner: the rest of the hour it has been billed). |

### Unpark [#unpark]

```csharp
bool Unpark(IWorkerHandle handle);
```

Bring a parked instance back. True when the handle is [`WorkerHandleState.Running`](/docs/reference/orchestrator/worker-handle-state#running) again and the worker it holds keeps its id and index; false when the host has already dropped it, in which case the orchestrator launches a fresh worker instead.
