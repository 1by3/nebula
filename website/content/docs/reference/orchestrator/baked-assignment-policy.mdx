public sealed class BakedAssignmentPolicy : IAssignmentPolicy

The original policy: baked containers are dealt as evenly as possible by count, sticky to their owner, in wire order when that order is spatial ([`NebulaOrchestrator.ComputeAssignment`](/docs/reference/orchestrator/nebula-orchestrator#computeassignment)). Runtime containers stay with the worker that asked for them and only move when that worker is gone ([`NebulaOrchestrator.ComputeRuntimeAssignment`](/docs/reference/orchestrator/nebula-orchestrator#computeruntimeassignment)).
