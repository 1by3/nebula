How much of a worker's tick budget each container is costing, by container id: its worker's p90 utilization spread over the containers it leases in proportion to their cost-weighted occupancy ([`WorkerLoadTracker.Attribute`](/docs/reference/orchestrator/worker-load-tracker#attribute)). 0.4 means "four tenths of a tick". ### Hints [#hints]

What the game says about each container beyond what the mesh can measure, by container id ([`ContainerHint`](/docs/reference/containers/container-hint)). Containers nobody hinted are absent, which reads as [`ContainerHint.Default`](/docs/reference/containers/container-hint#default).

### DropHeldChanges [#dropheldchanges]

```csharp
public int DropHeldChanges(List<KeyValuePair<string, string>> changes);
```

Remove the changes that would move a held container, so a hold defers a rebalance whichever policy computed it. A hold never keeps an **orphan** where it is: a container with no live owner has to be placed, and the hold is about not being moved, not about staying unowned. Returns how many were dropped.
