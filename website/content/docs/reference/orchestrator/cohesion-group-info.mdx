One entity cohesion group as the orchestrator sees it: the union of what every worker reported about the members it owns ([`NebulaWorker.CohesionSpan`](/docs/reference/worker/nebula-worker#cohesionspan), `docs/cohesion-hints.md` D7). The planner deals its containers as one item, so the group never ends up split across two workers.
