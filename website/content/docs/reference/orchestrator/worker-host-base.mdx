public abstract class WorkerHostBase : IWorkerHost

Base class for hosts that do not park: [`Park`](#park) kills, [`Unpark`](#unpark) fails, and the orchestrator never parks into them. Deriving from this keeps a host source-compatible when [`IWorkerHost`](/docs/reference/orchestrator/i-worker-host) grows optional members.
