The data behind the World map page of the Nebula Dashboard (`/map`). It has two halves:

- **Geometry**, built once on the orchestrator's main thread from [`ContainerRegistry`](/docs/reference/containers/container-registry) and the world definition: every static container's box in absolute world coordinates, its cell, the container that encloses it and its neighbours (`GET /api/map/geometry`).
- **Telemetry**, the latest document each worker posted ([`WorkerTelemetry`](/docs/reference/worker/worker-telemetry), `POST /api/telemetry`): entity counts per container, the pose of every carried container whose carrier it simulates, the cells it has loaded and, while somebody has the map open, its authoritative entities (`GET /api/map`).

Thread-safe: workers post, and the page reads, on the dashboard's listener threads. Worker documents are kept as received and spliced into the map document unparsed (the runtime carries no JSON reader); the page does the aggregation.

### Accept [#accept]

```csharp
public string Accept(string json, out bool detail);
```

Store a worker's telemetry document, replacing its previous one. The document must be a JSON object whose first property is `"worker"`, as [`WorkerTelemetry`](/docs/reference/worker/worker-telemetry) writes it. Returns null when it was stored, otherwise why it was refused. `detail` is the answer for the worker: whether its next document should include entities.

The live map document: every worker's latest telemetry, with its age in seconds, sorted by worker id. Reading it marks the map as watched, which asks workers for their entities ([`DetailWanted`](#detailwanted)).

### BuildGeometryJson [#buildgeometryjson]

```csharp
public static string BuildGeometryJson(NebulaConfig config);
```

Every static container of the loaded level as the map draws it: its box in absolute world coordinates ([`ToAbsolute`](#toabsolute)), its cell in a partitioned world, the smallest container enclosing it and its static neighbours, plus the world's cells and the ghost band and hysteresis the mesh runs with. Main thread.

### ToAbsolute [#toabsolute]

```csharp
public static void ToAbsolute(Vector3 frame, out double x, out double y, out double z);
public static void ToAbsolute(Vector3 frame, Vector3Int originCell, Vector3 cellSize, out double x, out double y, out double z);
```

Absolute world position of a position in this process's frame. Without a partitioned world the frame is the world. With one, every process keeps its own floating origin ([`WorldOrigin`](/docs/reference/world/world-origin)), so the origin cell's offset is added back: two workers report the same place with the same numbers.
