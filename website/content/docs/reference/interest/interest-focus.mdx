One place a client is interested in: a point (the usual case, its pawn) or a box (a portal's window, an RTS selection). Positions are absolute world coordinates in double, like every other interest input, so a floating-origin shift changes nothing.

The entity this focus follows, when it follows one (the pawn, an owned unit). 0 otherwise.

### Space [#space]

```csharp
public ulong Space;
```

The region space the focus is in ([`RegionKeys.FrameKeyOf`](/docs/reference/interest/region-keys#framekeyof)): 0 for the scope's own space, or a physics frame with regions of its own, whose coordinates [`X`](#x), [`Y`](#y) and [`Z`](#z) are then in. A focus only sees entities of its own space (`docs/container-tree.md` D18).

### Scope [#scope]

```csharp
public ulong Scope;
```

The scope the focus is in when that is not the client's own ([`HasScope`](#hasscope)): a portal's window onto another scope, whose regions are salted with that scope (`docs/portals.md` D23). A focus with a scope sees only the entities of that scope.

### HasScope [#hasscope]

```csharp
public bool HasScope;
```

Whether [`Scope`](#scope) is set. A focus without one is in the client's own scope, and the public world is scope 0.
