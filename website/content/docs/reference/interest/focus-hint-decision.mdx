What the server decided about one incoming focus hint: which mode to treat it in, and the point itself (a policy may move it — snap an RTS camera to the territory it is allowed to watch, say). A struct, so the hook on the hot path allocates nothing.

## Fields

### Mode [#mode]

```csharp
public FocusMode Mode;
```

How the point is treated. [`FocusMode.Disabled`](/docs/reference/interest/focus-mode#disabled) drops the hint entirely.

### X, Y, Z [#x-y-z]

```csharp
public double X, Y, Z;
```

The hinted point in absolute world coordinates, as the client sent it or as the policy moved it.

