A uniform spatial hash over **absolute** world coordinates: the region arithmetic every part of interest management shares (gateway, worker, standalone services). One region is one cell of the grid; its id is the pinned three-axis 21-bit packing `RuntimeGrid.PackId` uses, so a chunked world's region ids and its container ids are literally the same numbers.

Positions are doubles because a region key must not depend on the floating origin: wire poses are container-local, and both ends add the container's absolute center in double before asking for a key. Shift the origin and every key stays what it was, which is what lets a gateway and a worker with different origins agree on one set of subscribed regions.

The packing is duplicated here rather than called: `RuntimeGrid` lives in the Unity-only `Nebula.World` assembly, which the standalone gateway does not compile. `InterestPackingPinTests` asserts the two agree for sample coordinates, and neither may change: ids are persisted.

### Resolve [#resolve]

```csharp
public static InterestGrid Resolve(in InterestSettings settings, double worldCellX, double worldCellY, double worldCellZ, bool cellsCentred);
public static InterestGrid Resolve(in InterestSettings settings, double worldCellSize = 0, bool cellsCentred = false);
```

Derive the grid both ends must agree on from the resolved settings and, when the game has a world definition, its cell size. The edge is snapped to an integer division of the cell so region edges coincide with cell edges, and the offset places region boundaries on those cell edges. Baked cells are centered on `coord × CellSize` (`cellsCentred`: offset −CellSize/2); `RuntimeGrid` cells start at `coord × CellSize` (offset 0). Pass 0 for no world definition.
