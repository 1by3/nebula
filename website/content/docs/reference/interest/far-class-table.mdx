The far classes resolved from [`InterestSettings`](/docs/reference/interest/interest-settings): a lookup by id, the default class (id 0, budget [`InterestSettings.FarMaxEntities`](/docs/reference/interest/interest-settings#farmaxentities) unless the list replaces it) and the order classes are served in. Built once per settings and shared by the worker (rates and radii) and the gateway (budgets). An entity that names a class the table does not define is in the default class.
