```csharp
public sealed class DefaultInterestPolicy : IInterestPolicy
```

What a mesh does without a game policy: one focus at the pawn, plus the client's validated hint as a second focus when it has sent one. A client with no pawn gets no focus, and so hears only about globally relevant entities; a game that wants spectators gives them a focus in its own policy.
