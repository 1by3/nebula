The identity of one cross-worker call: the sending worker's index in the top 16 bits and a per-sender sequence in the low 48, the same shape as an entity `NetId`. Forwarding keeps the id, so every worker on the path and the reply agree on which call they mean.

### InitialSequence [#initialsequence]

```csharp
public static ulong InitialSequence(uint incarnation);
```

Where a sender's sequence starts for one run of its process: the low 16 bits of its incarnation, shifted above 32 bits of room. A worker that restarts with the same index therefore mints ids a previous run never used, and a receiver's ledger cannot mistake its first calls for duplicates of the old run's.
