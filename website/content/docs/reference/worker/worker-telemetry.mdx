Reports what a worker holds to the World map of the Nebula Dashboard ([`MeshTelemetry`](/docs/reference/orchestrator/mesh-telemetry)):

- for every container with anything in it on this worker, how many players, bots, server-driven and other authoritative entities it holds there, and how many ghosts;
- the box, pose and velocity of every carried container ([`DynamicContainer`](/docs/reference/containers/dynamic-container)) whose carrier this worker simulates, with the container the carrier sits in;
- the cells it has loaded, in a partitioned world;
- and, only while somebody has the map open, one point per authoritative entity.

Positions are absolute world coordinates, so workers with different floating origins agree. The document is posted to `-nebula-telemetry <url>` (the orchestrator passes its own dashboard's `/api/telemetry` to every worker it launches), or handed straight to an orchestrator in the same process. It is built in `Update`, never inside the tick, every [`IdleIntervalSeconds`](#idleintervalseconds) or [`DetailIntervalSeconds`](#detailintervalseconds) while the map is watched, and sent from the thread pool; a post still in flight skips the next one rather than queueing.
