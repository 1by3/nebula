The sender's side of the reply channel: the calls this worker sent with a reply requested and has not heard back about. Each settles exactly once, with the reply that arrives or with [`AuthorityCallOutcome.TimedOut`](/docs/reference/worker/authority-call-outcome#timedout) when [`Expire`](#expire) passes its deadline.
