Reads a worker's memory figures for its heartbeat and its profile log line. It runs at heartbeat rate (once every [`NebulaConfig.WorkerHeartbeatSeconds`](/docs/reference/core/nebula-config#workerheartbeatseconds)), keeps one `Process` object and refreshes it, and allocates nothing per call beyond what the OS query itself needs.
