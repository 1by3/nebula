The rules every worker applies to an incoming `AuthorityRpc` call, in one place and with no engine types, so the worker, the standalone services and the conformance tests run the same code. The rules, in the order they are checked:

1. The entity is unknown here: [`AuthorityCallOutcome.RejectedUnknownEntity`](/docs/reference/worker/authority-call-outcome#rejectedunknownentity).
2. The call's epoch is ahead of the entity's, or more than [`MaxHops`](#maxhops) behind it: [`AuthorityCallOutcome.RejectedStaleEpoch`](/docs/reference/worker/authority-call-outcome#rejectedstaleepoch). A handover bumps the epoch by one and costs one forward, so a call that reached its authority within the hop bound is never more than [`MaxHops`](#maxhops) behind; anything further behind came from a copy that had missed several authority changes (design D3).
3. This worker has authority: apply, unless the ledger has the id, which is [`AuthorityCallOutcome.RejectedDuplicate`](/docs/reference/worker/authority-call-outcome#rejectedduplicate) (design D5).
4. The call has already been forwarded [`MaxHops`](#maxhops) times: [`AuthorityCallOutcome.RejectedHopLimit`](/docs/reference/worker/authority-call-outcome#rejectedhoplimit) (design D4).
5. There is a peer to forward to: forward. Otherwise [`AuthorityCallOutcome.RejectedUnreachable`](/docs/reference/worker/authority-call-outcome#rejectedunreachable).

## Methods

### Decide [#decide]

```csharp
public AuthorityCallDecision Decide(ulong callId, uint callEpoch, byte hops, in AuthorityCallTarget target, uint tick);
```

Decide what to do with a call and record the decision. An [`AuthorityCallAction.Apply`](/docs/reference/worker/authority-call-action#apply) has already put the call id in the [`Ledger`](#ledger) when this returns; the caller runs the method exactly then.

| Parameter | Description |
| --- | --- |
| `callId` | The id the sender minted. |
| `callEpoch` | The entity epoch the sender observed when it made the call. |
| `hops` | How many times the call has been forwarded before reaching this worker. |
| `target` | What this worker knows about the entity. |
| `tick` | This worker's current tick, for the ledger. |
