### RegisterAgainIfForgotten [#registeragainifforgotten]

```csharp
public bool RegisterAgainIfForgotten(IControlPlane controlPlane);
```

Requests registration again if the connected control plane no longer lists this worker. Call from [`IControlPlane.Changed`](/docs/reference/control-plane/i-control-plane#changed) after initial registration; polling can issue duplicate requests while a remote control plane is waiting for the updated document.

**Returns:** True if this call issued a registration request. The worker can then send a heartbeat immediately.

### IsDeclaredDead [#isdeclareddead]

```csharp
public bool IsDeclaredDead(IControlPlane controlPlane);
```

Whether the control plane has declared this worker dead: a document this worker has been listed in no longer lists it. The orchestrator removes the row of a worker whose heartbeats stopped and deals its containers to someone else, so the leases this worker still simulates may be restored elsewhere from their last checkpoint (`docs/persistence-durability.md` D10). A row missing from a *replacement* document is a control plane that came back empty, not a verdict: that is [`ReclaimContainers`](#reclaimcontainers)' case (`docs/control-plane-availability.md` D1b). Call before [`RegisterAgainIfForgotten`](#registeragainifforgotten), which can put the row straight back on an in-process control plane.

### IsFenced [#isfenced]

```csharp
public bool IsFenced(IControlPlane controlPlane, float timeoutSeconds);
```

Whether this worker must stop acting as the owner of its leases: it has been declared dead ([`IsDeclaredDead`](#isdeclareddead)), or its own row, as its mirror of the control plane shows it, has not had a heartbeat for more than `timeoutSeconds` — the same test, on the same clock, the orchestrator applies before it declares a worker dead. A fenced worker writes nothing to the persistence store, reads nothing back and hands nothing over; it keeps simulating, and it is unfenced by its next heartbeat landing (`docs/persistence-durability.md` D8). False before the worker has seen its own row in the current document: nothing is leased to it there yet.

### ReclaimContainers [#reclaimcontainers]

```csharp
public int ReclaimContainers(IControlPlane controlPlane);
```

Requests missing leases, which assign containers to workers, for containers this worker still owns. Call on each control-plane change before applying the updated leases. Reconciliation runs once for each new [`IControlPlane.DocumentId`](/docs/reference/control-plane/i-control-plane#documentid); removals within the same document are preserved.

Existing leases and dynamic containers are skipped. Runtime containers are reclaimed with their bounds and instance metadata; other containers are ensured and assigned to this worker.

**Returns:** The number of containers for which this call issued reclaim requests.
