Requests the initial worker registration when the control plane is connected. Does nothing if registration has already been requested.

**Returns:** True if this call issued a registration request.

### RegisterAgainIfForgotten [#registeragainifforgotten]

```csharp
public bool RegisterAgainIfForgotten(IControlPlane controlPlane);
```

Requests registration again if the connected control plane no longer lists this worker. Call from [`IControlPlane.Changed`](/docs/reference/control-plane/i-control-plane#changed) after initial registration; polling can issue duplicate requests while a remote control plane is waiting for the updated document.

**Returns:** True if this call issued a registration request. The worker can then send a heartbeat immediately.

### Forget [#forget]

### ReclaimContainers [#reclaimcontainers]

```csharp
public int ReclaimContainers(IControlPlane controlPlane);
```

Requests missing leases, which assign containers to workers, for containers this worker still owns. Call on each control-plane change before applying the updated leases. Reconciliation runs once for each new [`IControlPlane.DocumentId`](/docs/reference/control-plane/i-control-plane#documentid); removals within the same document are preserved.

Existing leases and dynamic containers are skipped. Runtime containers are reclaimed with their bounds and instance metadata; other containers are ensured and assigned to this worker.

**Returns:** The number of containers for which this call issued reclaim requests.
