Where the orchestrator keeps the control plane and saved entities, as one string ([`NebulaConfig.DatabaseUrl`](/docs/reference/core/nebula-config#databaseurl), `-nebula-database`).

- `sqlite:<file>`: a SQLite database file (standalone orchestrator; the default for a local mesh).
- `postgres://user:password@host:port/database` (or `postgresql://`, or a `Host=...;` connection string): a PostgreSQL database (standalone orchestrator; for a deployed mesh).
- `file:<folder>`: plain files in a folder (the Unity orchestrator, which carries no database driver).
- `memory`: nothing survives the process.
