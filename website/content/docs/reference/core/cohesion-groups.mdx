Which entities belong to which [`NetworkIdentity.CohesionGroup`](/docs/reference/core/network-identity#cohesiongroup), in this process. A cohesion group is the game's promise that a set of entities must be simulated by one worker and move between workers as a unit: a ragdoll's bodies, a turret and its mount, the two sides of an interaction that is mid-flight. Nebula never guesses a group (see `docs/cohesion-hints.md`, D1); the game joins and leaves one.

The table is process-wide, like [`SceneEntities`](/docs/reference/core/scene-entities), and holds every initialised identity that carries a non-zero group - authoritative copies, ghosts and client replicas alike. Callers that mean "the members I own" filter by [`NetworkIdentity.HasAuthority`](/docs/reference/core/network-identity#hasauthority); [`NebulaWorker`](/docs/reference/worker/nebula-worker) does, and a member it finds that it does not own is a group it cannot move as a unit, which it reports rather than splitting silently (D4).

Group 0 is "no group" and is never stored, so a game that uses no cohesion group pays an empty table.
