What an entity looked like at one recorded server tick: the answer of [`NetworkIdentity.StateAt`](/docs/reference/core/network-identity#stateat). Check [`Available`](#available) first; every other member is meaningless when it is false. [`Tick`](#tick) is the tick the entry was actually recorded for, which is the asked-for tick unless it fell in a gap (see [`StateHistory.GapToleranceTicks`](/docs/reference/core/state-history#gaptoleranceticks)).

### FromAuthority [#fromauthority]

```csharp
public bool FromAuthority { get; }
```

True when this worker recorded the entry as the authority (after that tick's simulation), false when it recorded it as a ghost holder from the owner's stream. A ghost entry is one tick behind the owner in availability, never in the tick it is tagged with; see `docs/state-history.md` §4.
