A server-authoritative, client-predicted behaviour (the player controller, typically).

- On the owning client, [`GatherInput`](#gatherinput) runs every tick, the input is sent and [`Simulate`](#simulate) is run immediately (prediction).
- On the authoritative worker, [`Simulate`](#simulate) runs with the input for that tick. When the entity crosses to another worker the buffered inputs travel with it, so the input stream never breaks.
- The worker reports its post-simulation state to the owner; if the client's prediction for that tick disagrees by more than [`CorrectionThreshold`](#correctionthreshold), the client rewinds and replays.
