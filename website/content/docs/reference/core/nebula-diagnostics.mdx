Process-wide counters for rule violations Nebula rejects at the call site, so tests and the worker's `profile` log line can see how often game code hits them.

## Properties

### RejectedAuthorityRpcSends [#rejectedauthorityrpcsends]

```csharp
public static int RejectedAuthorityRpcSends { get; }
```

How many `AuthorityRpc` sends this process discarded because the caller held neither an authoritative nor a ghost copy of the entity (a client, an unspawned entity). Each one is also logged through [`NebulaLog.Warn`](/docs/reference/core/nebula-log#warn). [`NebulaWorker.RejectedAuthorityRpcSends`](/docs/reference/worker/nebula-worker#rejectedauthorityrpcsends) reads it.

### SplitCohesionGroups [#splitcohesiongroups]

```csharp
public static int SplitCohesionGroups { get; }
```

How many handovers this worker could not carry out as a unit because a member of the entity's [`NetworkIdentity.CohesionGroup`](/docs/reference/core/network-identity#cohesiongroup) was not owned here (`docs/cohesion-hints.md`, D4). Each one is also logged through [`NebulaLog.Warn`](/docs/reference/core/nebula-log#warn). A group is never split silently.

### PortalCloseOverruns [#portalcloseoverruns]

```csharp
public static int PortalCloseOverruns { get; }
```

How many portal links closed because the band never emptied within [`Portal.CloseTimeoutSeconds`](/docs/reference/containers/portal#closetimeoutseconds) (`docs/portals.md` D9, D36). Each one is also logged through [`NebulaLog.Warn`](/docs/reference/core/nebula-log#warn).

### PortalRefusals [#portalrefusals]

```csharp
public static int PortalRefusals { get; }
```

How many crossings portals refused: an entity that met the aperture while its link was not open, or that was not admitted (`docs/portals.md` D17, D36).

public static int OpenPortalLinks { get; }

How many portal links are open on this worker right now (`docs/portals.md` D36).

### SplitPortalLinks [#splitportallinks]
