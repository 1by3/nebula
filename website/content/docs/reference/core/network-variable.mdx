Replicated field, NGO-style: declare it on a [`NetworkBehaviour`](/docs/reference/core/network-behaviour) and Nebula discovers it. Only the authoritative worker may assign [`Value`](#value); every other copy (ghosts on neighbouring workers, clients) receives it and raises [`OnValueChanged`](#onvaluechanged).

```csharp
public NetworkVariable<float> Health = new NetworkVariable<float>(100f);
```
