A keyed collection replicated from the authoritative worker to clients and ghost workers, sending only what changed. Declare it on a [`NetworkBehaviour`](/docs/reference/core/network-behaviour) like a [`NetworkVariable<T>`](/docs/reference/core/network-variable), and add [`PersistAttribute`](/docs/reference/persistence/persist-attribute) to save it:

```csharp
[Persist] public NetworkMap<int, ItemStack> Slots = new NetworkMap<int, ItemStack>();
```

Only the authority may write it. Each tick, the keys that changed go out as one reliable message; a client that arrives later is given the current contents by its gateway, then the same changes as everyone else. Keys and values use [`NetworkSerialization`](/docs/reference/serialization/network-serialization), so any type a [`NetworkVariable<T>`](/docs/reference/core/network-variable) can hold works. A map is capped at [`NetworkMapBase.Capacity`](/docs/reference/core/network-map-base#capacity) encoded bytes (60 KB by default).

### this\[\] [#this]

```csharp
public TValue this[TKey key]
{
    get => _map[key];
    set
    {
        if (!TrySet(key, value))
            throw new InvalidOperationException(CapMessage(key));
    }
}
```

Get a value, or (authority) add or replace one. Setting a value equal to the current one does nothing. Throws `InvalidOperationException` when the map would pass its size cap.

## Events

### OnChanged [#onchanged]

```csharp
public event Action<NetworkMapChange<TKey, TValue>> OnChanged;
```
