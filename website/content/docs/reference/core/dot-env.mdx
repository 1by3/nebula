Reads and writes dotenv files (`.env.nebula`, the file `NEBULA_ENV_FILE` names, `nebula env pull` output), and holds the rules for the names of the environment variables a game gives its workers. The same code runs in the Unity runtime, the standalone services and the CLI.

The format, one variable per line:

- `KEY=value`. Spaces around the `=` and around an unquoted value are dropped, and so is an unquoted value's trailing comment (` # ...`, a `#` after whitespace).
- `export KEY=value`: the `export` is ignored, so a file can be sourced by a shell too.
- `KEY='value'`: taken literally. It may span several lines.
- `KEY="value"`: `\n`, `\r`, `\t`, `\"` and `\\` are escapes. It may span several lines.
- Blank lines and lines starting with `#` are skipped. Nothing is expanded: `$OTHER` stays as written.
- When a key appears twice, the last one wins.
