## Fields

### ClientId [#clientid]

```csharp
public readonly ulong ClientId;
```

The player's session id: unique across every gateway of the mesh, and kept across a reconnection with a session token (the player continues with the same pawn). A new session gets a new id.

### Name [#name]

```csharp
public readonly string Name;
```

The player's display name: the verified token's [`NebulaConfig.NameClaim`](/docs/reference/core/nebula-config#nameclaim) when the mesh sets one and the token has it, otherwise the name the client asked for.

### Identity [#identity]

```csharp
public readonly string Identity;
```

The player's identity across sessions ([`PlayerIdentity`](/docs/reference/gateway/player-identity)): from the OpenID token they presented, or the anonymous token the gateway issued them.

### IsBot [#isbot]

```csharp
public readonly bool IsBot;
```

The client is a headless bot.

## Properties

### Claims [#claims]

```csharp
public IReadOnlyDictionary<string, string> Claims { get; }
```

The claims of the player's verified sign-in token that the mesh forwards ([`NebulaConfig.ForwardedClaims`](/docs/reference/core/nebula-config#forwardedclaims)), every value a string. Empty, never null, for anonymous players and when nothing is forwarded. The pawn carries the same claims as [`NetworkIdentity.OwnerClaims`](/docs/reference/core/network-identity#ownerclaims).
