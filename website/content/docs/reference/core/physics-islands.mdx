Decides whether two networked bodies are simulated by one authority (the same *island*) and finds the joints that are not. Nebula simulates a dynamic body only on the worker that has authority over its entity; every other worker holds a kinematic ghost one tick behind. A `Joint` or `ArticulationBody` between entities in different containers can therefore have each of its two bodies simulated by a different worker, and PhysX on each side solves the constraint against a kinematic copy. Nebula does not make that symmetric. `Nebula > Validate Project` and the worker use this class to warn about such constraints; see Distributed physics.

### FindCrossIslandJoints [#findcrossislandjoints]

```csharp
public static int FindCrossIslandJoints(NetworkIdentity root, List<CrossIslandJoint> results, Func<NetworkIdentity, Container> resolve = null);
```

Appends every constraint under `root` whose two bodies are in different islands. A constraint is attributed to the nearest [`NetworkIdentity`](/docs/reference/core/network-identity) above it, so a constraint on a nested entity's hierarchy is reported from that entity, not from its carrier. A joint connected to the world (no connected body) or to a body without a NetworkIdentity is never reported: nothing else simulates that body. Returns the number of constraints added.
