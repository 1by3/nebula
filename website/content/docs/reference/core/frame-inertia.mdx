Lets a physics prop inside a moving physics frame feel the frame's motion: crates slide aft when the ship accelerates, outwards when it turns. A physics frame ([`Container.OwnPhysicsFrame`](/docs/reference/containers/container#ownphysicsframe)) is a scene in which its container stands still, so without this component nothing inside feels the carrier move at all.

On the authority, every [`NetworkBehaviour.NetworkTick`](/docs/reference/core/network-behaviour#networktick), before the frame's scene steps, the body gets the fictitious acceleration of its frame, `-(A + α × r + ω × (ω × r) + 2 ω × v)`, as `ForceMode.Acceleration`: `A` and `ω` are the frame's acceleration and angular velocity in its own axes ([`PhysicsFrameState.LocalAcceleration`](/docs/reference/containers/physics-frame-state#localacceleration), [`PhysicsFrameState.LocalAngularVelocity`](/docs/reference/containers/physics-frame-state#localangularvelocity)), `α` the rate of change of `ω`, `r` and `v` the body's frame-local position and velocity. Each tick's value is multiplied by [`Scale`](#scale), clamped to [`MaxAcceleration`](#maxacceleration), then smoothed over [`SmoothingTicks`](#smoothingticks); below [`MinAcceleration`](#minacceleration) nothing is applied, so a crate in a cruising ship can sleep. The frame's state is sampled once per tick after the carriers moved, so the force follows the carrier one tick late.

Outside a physics frame, on a ghost, on a client and while the body is kinematic it does nothing. The frame's own gravity is not rotated: "down" stays the container's floor. Add it next to a [`NetworkRigidbody`](/docs/reference/core/network-rigidbody). See `docs/frame-bodies.md` D4.

## Fields

### Scale [#scale]

```csharp
public float Scale = 0f;
```

How much of the frame's motion the body feels: 0 none (the default), 1 all of it. Games usually set it per ship, like an inertial damper.

### MaxAcceleration [#maxacceleration]

```csharp
public float MaxAcceleration = 20f;
```

The largest fictitious acceleration applied in one tick, in m/s² after Scale. Keeps a snap of the carrier (a teleport, a landing) from launching the cargo.

### SmoothingTicks [#smoothingticks]

```csharp
public int SmoothingTicks = 6;
```

Ticks the acceleration is smoothed over (an exponential moving average). 1 applies each tick's value as it is.

### MinAcceleration [#minacceleration]

```csharp
public float MinAcceleration = 0.05f;
```

Below this acceleration, in m/s², nothing is applied, so a body at rest in a cruising ship can sleep.
