Runs on every client that knows the entity (or only its owner when sent with OwnerRpc).

## Fields

### Radius [#radius]

```csharp
public float Radius;
```

Metres. When set, the gateway delivers a broadcast of this RPC only to clients whose pawn is within this distance of the entity (a tracer, a footstep, a muzzle flash: nobody across the map needs it). 0 (the default) reaches every client. Targeted sends (OwnerRpc) are never filtered.
