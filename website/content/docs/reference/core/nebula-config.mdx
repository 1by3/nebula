Project-wide Nebula settings. Workers and clients load Resources/NebulaConfig. Builds export its settings to nebula-services.json for the standalone orchestrator and gateway. Command-line switches override fields at runtime.

### AutoScale [#autoscale]

```csharp
public bool AutoScale = true;
```

Keep the worker count between MinWorkers and MaxWorkers from how busy the workers are: add one when the busiest worker's tick time stays over ScaleOutUtilization of the tick budget, remove one when the mesh's mean stays under ScaleInUtilization. Every change is checked against a dry run of the assignment policy first.
