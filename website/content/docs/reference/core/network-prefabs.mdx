Prefab id table shared by every process. Ids are the index in [`NebulaConfig.NetworkPrefabs`](/docs/reference/core/nebula-config#networkprefabs). Ids from [`BuiltInBase`](#builtinbase) up are reserved for prefabs Nebula itself provides (such as the entity behind `Nebula.World.ChunkState`): every process builds them the same way, so a game never lists them and they never shift when the game's list changes.
