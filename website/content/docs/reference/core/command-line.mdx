Tiny "-key value" / "-key=value" / "-flag" parser over `Environment.GetCommandLineArgs`. A web build has no command line and reads the same switches from the page's query string instead: `?nebula-name=Jesse&nebula-connect`.

Every switch that was parsed, for a service that forwards a whole family of them (`-nebula-ext-*`) to a process it launches.

## Methods

### ParseArgs [#parseargs]

```csharp
public static void ParseArgs(IReadOnlyList<string> raw, int start, IDictionary<string, string> into);
```

Adds switches from an argument vector to `into`, starting at `start` (1 skips the executable). Both spellings work: `-key value` and `-key=value`; the second is the only way to pass a value that itself starts with a dash (`-heading=-30`). A switch with no value maps to the empty string.

### ParseQuery [#parsequery]

```csharp
public static void ParseQuery(string url, IDictionary<string, string> into);
```

Adds the parameters of a URL's query string ("a=1&b") to `into`, URL-decoded, with any leading dashes removed from the keys.
