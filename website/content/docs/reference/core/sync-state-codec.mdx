Envelope shared by the per-tick sync stream (EntityState/GhostSyncState messages) and the spawn snapshot: `[count]{[behaviourIndex][flags][len:ushort][chunk]}`. Each chunk is bounded so a behaviour that reads too much or too little cannot corrupt its neighbours. Kept free of NetworkIdentity so the gateway can cache keyframes without instantiating anything.
