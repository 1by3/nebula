### InputLeadMin [#inputleadmin]

```csharp
public int InputLeadMin { get; } = int.MaxValue;
```

Server: the smallest input lead (input tick minus the worker's current tick at arrival) seen since the last [`TakeInputLead`](#takeinputlead). An input only gets simulated when it arrives with a lead of at least 1; the owner uses this to stretch or relax how far ahead it sends. `int.MaxValue` while nothing arrived.
