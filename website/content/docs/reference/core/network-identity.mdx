Marks a GameObject as a networked entity. Holds the entity's network identity (a 64-bit ID created by the worker that spawned it, never by a central allocator), its current container, its authority epoch and which worker/client owns it. Every [`NetworkBehaviour`](/docs/reference/core/network-behaviour) on the object hangs off this. Add [`NetworkTransform`](/docs/reference/core/network-transform) for ongoing transform replication and [`NetworkRigidbody`](/docs/reference/core/network-rigidbody) for worker-simulated physics. An identity alone only synchronizes placement at spawn and container changes.

### CostWeight [#costweight]

```csharp
public float CostWeight = 1f;
```

What this entity costs to simulate, as a multiplier on its category weight in NebulaConfig.CostWeights. 1 (the default) leaves balancing exactly as it was; 8 on a raid boss and 0.25 on an ambient critter tell the planner and the scaler that they are not the same machine. NebulaCost.EntityWeight can override it at spawn; NetworkIdentity.SetCostWeight overrides both.

### ColliderExtentRefreshTicks [#colliderextentrefreshticks]

```csharp

```

With [`EntityExtentSource.Colliders`](/docs/reference/protocol/entity-extent-source#colliders), the box is computed again at least this often, in ticks of the worker that holds authority. Nothing tells Nebula that a collider deeper than a direct child changed; call [`RefreshExtent`](#refreshextent) when a change must count sooner.

### SyncKeyframeInterval [#synckeyframeinterval]

```csharp

```

Every this many ticks a dirty sync behavior writes a keyframe instead of a delta, and an unreliable one writes a keyframe whether it is dirty or not. Keyframes heal lost packets and are what the gateway hands to late joiners.

### EffectiveCostWeight [#effectivecostweight]

```csharp
public float EffectiveCostWeight { get; } = 1f;
```

The multiplier this entity actually carries right now (see [`NebulaCost`](/docs/reference/core/nebula-cost) for how it is chosen). It is computed at spawn, travels with the entity through ghosting and handover, and only changes when the game calls [`SetCostWeight`](#setcostweight): never per tick. Multiply it by the entity's category weight in [`CostWeights`](/docs/reference/orchestrator/cost-weights) to get what the mesh thinks it costs.

### ExtentSource [#extentsource]

```csharp
public EntityExtentSource ExtentSource { get; }
```

Where this entity's extent comes from (`docs/entity-extents.md`). With [`EntityExtentSource.None`](/docs/reference/protocol/entity-extent-source#none), the default, the ghost band measures from the entity's root position, as it always has. With an extent it measures from the extent's box, so the entity is ghosted to every worker whose container the box comes within [`NebulaConfig.GhostBandMargin`](/docs/reference/core/nebula-config#ghostbandmargin) of. An extent never changes which worker has authority: that still follows the root position.

### SetExtent [#setextent]

```csharp
public void SetExtent(Bounds localBounds);
```

Give the entity an explicit extent: a box in its local space (the root's rotation and scale apply to it). Call it on the authority when the entity's shape changes, for example after a structure is edited; the next tick's ghost band uses it. The box travels with a handover and is saved by a [`PersistentEntity`](/docs/reference/persistence/persistent-entity). A negative size is taken as its absolute value.

### UseColliderExtent [#usecolliderextent]

```csharp
public void UseColliderExtent();
```

Measure the entity by its own colliders from now on: every enabled, non-trigger collider on an active object under it whose nearest [`NetworkIdentity`](/docs/reference/core/network-identity) is this one. The box is computed when it is next needed, then again every [`ColliderExtentRefreshTicks`](#colliderextentrefreshticks) ticks, when a direct child is added or removed, and after [`RefreshExtent`](#refreshextent) is called.

### JoinCohesionGroup [#joincohesiongroup]

Put this entity in a cohesion group, leaving the one it was in. The authority's value is the one that counts: it is what a handover expands and what the worker reports to the orchestrator. ### PlaceInScope [#placeinscope]

```csharp
public void PlaceInScope(Vector3 position, Quaternion rotation);
```

Authority: put the entity at a pose given in its scope's own space (a respawn point, a warp target), leaving any physics frame it is in first. Writing such a pose straight onto the transform of an entity inside a frame would put it at those numbers in the frame's coordinates. When the target is inside a frame (a ship's interior), the entity lands in that frame at the matching frame-local pose. Outside frames this is a plain assignment; the next tick resolves the container as usual.

### StateAt [#stateat]

What this entity looked like at server tick `tick`: its world pose, velocity, container, epoch and the [`SyncHistoryAttribute`](/docs/reference/core/sync-history-attribute) variables. ### WriteSyncState [#writesyncstate]

```csharp
public int WriteSyncState(NetworkWriter writer, uint tick, Delivery delivery);
public int WriteSyncState(NetworkWriter writer, uint tick, Delivery delivery, bool forGateway);
```

Authority, once per tick per delivery class and per destination: the chunks due this tick. A behavior is written when it is dirty, or (unreliable only) when a keyframe is due. The keyframe decision depends only on the tick and on state that [`ClearDirty`](#cleardirty) advances, so every destination written in the same tick gets identical chunks: the first tick after gaining authority is a keyframe for all of them. Returns the number of chunks written; when zero the writer has been left untouched.
