### Velocity [#velocity]

Linear velocity in the entity's own space: frame-local (relative to the ship) inside a physics frame ([`NetworkIdentity.Space`](/docs/reference/core/network-identity#space)), the scope's own space everywhere else. This is only streamed when a root NetworkTransform opts in. A change of space converts it ([`PhysicsFrames.ConvertVelocity`](/docs/reference/containers/physics-frames#convertvelocity)).
