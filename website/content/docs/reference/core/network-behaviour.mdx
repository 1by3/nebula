```csharp
[RequireComponent(typeof(NetworkIdentity))]
public abstract class NetworkBehaviour : MonoBehaviour
```

Base class for replicated gameplay components. Use [`IsServer`](#isserver), [`IsClient`](#isclient), and [`IsOwner`](#isowner) to inspect the current role. Use [`HasAuthority`](#hasauthority) to check whether this worker controls the entity, and [`IsGhost`](#isghost) to check whether it holds a non-authoritative copy. Override the lifecycle methods to respond to spawn, despawn, and authority changes.

### WriteHandoverState [#writehandoverstate]

```csharp
public virtual void WriteHandoverState(NetworkWriter writer);
```

Called on the outgoing worker while building an authority transfer, before [`OnLostAuthority`](#onlostauthority). Write any state the next owner needs that is not already replicated (angular velocity, timers, RNG state...). Travels only with the handover, never in the per-tick stream. Must be mirrored exactly by [`ReadHandoverState`](#readhandoverstate).

### ReadHandoverState [#readhandoverstate]

```csharp
public virtual void ReadHandoverState(NetworkReader reader);
```

Called on the incoming worker after the entity's pose, velocity and NetworkVariables have been applied and before [`OnGainedAuthority`](#ongainedauthority). Read exactly what [`WriteHandoverState`](#writehandoverstate) wrote.

### WritePersistentState [#writepersistentstate]

```csharp
public virtual void WritePersistentState(NetworkWriter writer);
```

Called while the worker builds this entity's persistence record. Write what the entity needs to come back as it was and that no [`PersistAttribute`](/docs/reference/persistence/persist-attribute) variable already covers. Must be mirrored exactly by [`ReadPersistentState`](#readpersistentstate). Writing nothing (the default) costs nothing: an entry is only added when bytes were written.

Unlike [`WriteHandoverState`](#writehandoverstate), this is read back by a later run and possibly a later build, so treat it as a save format and version it yourself if you expect it to change.

### ReadPersistentState [#readpersistentstate]

```csharp
public virtual void ReadPersistentState(NetworkReader reader);
```

Called on a restored entity before it is spawned, with exactly what [`WritePersistentState`](#writepersistentstate) wrote. The reader is bounded to this behaviour's own chunk, so reading too much fails here (and is logged) instead of corrupting the rest of the record.

### WriteSyncState [#writesyncstate]

```csharp
public virtual void WriteSyncState(NetworkWriter writer, bool full);
```

Authority only. Write the state to replicate. When `full` is true write everything (a keyframe: this is what a late joiner or a fresh ghost will start from); otherwise only what changed since the last write is needed, though writing everything is always correct.

### ReadSyncState [#readsyncstate]

```csharp
public virtual void ReadSyncState(NetworkReader reader, uint tick, bool full);
```

Non-authoritative copies. `tick` is the simulation tick the state belongs to (0 for a spawn snapshot); buffer it and present it from [`RemoteTick`](#remotetick), or apply it at once.

### OnSyncStateSent [#onsyncstatesent]

```csharp
protected internal virtual void OnSyncStateSent();
```

The tick's sends are done (every peer and gateway got this tick's chunk): drop per-tick pending deltas. Called from [`NetworkIdentity.ClearDirty`](/docs/reference/core/network-identity#cleardirty); the owning client calls it after its own send.

### RemoteTick [#remotetick]

```csharp
public virtual void RemoteTick(double renderTick);
```

Called on every copy this process does not simulate (ghosts on a worker: once per tick before physics syncs; entities on a client: once per frame) with the tick to present. Interpolating behaviours sample their buffers here. See [`NetworkTime.RenderTick`](/docs/reference/core/network-time#rendertick).
