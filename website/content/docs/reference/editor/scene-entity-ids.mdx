Gives every [`NetworkIdentity`](/docs/reference/core/network-identity) authored into a scene its [`NetworkIdentity.SceneId`](/docs/reference/core/network-identity#sceneid) when the scene is saved: a random non-zero id, unique within the scene, that then stays with the object for good. Prefab assets keep 0 (they are spawned by prefab id); an instance placed in a scene gets its id as an override. Cell scenes of a partitioned world are separate files, so ids are made unique across every scene that is open at the time as well.
