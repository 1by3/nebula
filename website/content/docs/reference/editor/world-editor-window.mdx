The World window (Nebula \> World): a map of the cell grid, one vertical layer at a time. Click an empty cell to create its scene, a defined cell to open or close it (open cells are placed next to each other in the scene view), right-click for more. Also bakes the container manifest and moves objects from a single-scene level into cells.
