One-click setup from the Nebula menu. **Set Up Active Scene** turns the open scene into a working Nebula game scene: the `Resources/NebulaConfig` asset, a `Nebula` object with [`NebulaBootstrap`](/docs/reference/bootstrap/nebula-bootstrap) and [`NebulaDebugOverlay`](/docs/reference/debug/nebula-debug-overlay), [`NebulaConfig.GameScene`](/docs/reference/core/nebula-config#gamescene), the build settings (the scene is the boot scene), the project's [`NebulaGameMode`](/docs/reference/core/nebula-game-mode), starter [`Container`](/docs/reference/containers/container) volumes around the level, and every networked prefab in [`NebulaConfig.NetworkPrefabs`](/docs/reference/core/nebula-config#networkprefabs). Every step is idempotent, so running it again on a configured scene changes nothing and it doubles as a repair.
