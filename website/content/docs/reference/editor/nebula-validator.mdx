Nebula \> Validate Project: checks the things that otherwise only show up as a broken build or a silent mesh. The config asset, the boot and game scenes in the build settings, the game mode, containers, the network prefab table, a partitioned world's manifest and cell scenes, static batching in cells and scene entities waiting for an id. Each issue is logged with its object as context, so clicking the log line selects it.
