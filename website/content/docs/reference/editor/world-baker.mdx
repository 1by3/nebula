public static class WorldBaker

Builds the [`WorldContainerManifest`](/docs/reference/world/world-container-manifest): one container per cell plus every [`Container`](/docs/reference/containers/container) authored inside the cell scenes, with cell-local poses, in wire order. Opens cell scenes that are not open (and closes them again) to read them.
