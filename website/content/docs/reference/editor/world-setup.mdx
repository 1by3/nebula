Nebula \> Set Up World Partition: makes the active scene the hub of a partitioned world in one pass. Runs the scene setup, finds or creates the [`WorldDefinition`](/docs/reference/world/world-definition) and its [`WorldContainerManifest`](/docs/reference/world/world-container-manifest), moves the level's root objects into cell scenes by position (cameras, directional lights, volumes, UI, the game mode, the bootstrap and anything selected stay in the hub), clears static batching on the moved content, saves, bakes the manifest, points [`NebulaConfig.WorldManifest`](/docs/reference/core/nebula-config#worldmanifest) at it and opens the World window. Idempotent like the scene setup: on a hub that is already partitioned it only rebakes.
