A player's identity across sessions: 64 lowercase hex characters, the SHA-256 of the token's issuer and subject. The same account at the same provider always maps to the same identity, and two providers can never collide. It is what [`NetworkIdentity.OwnerIdentity`](/docs/reference/core/network-identity#owneridentity) and [`NebulaClient.Identity`](/docs/reference/client/nebula-client#identity) carry, and what a game keys player records on (for example a [`PersistentEntity.Key`](/docs/reference/persistence/persistent-entity#key)).
