Issues and checks the session tokens a gateway gives every welcomed client ([`WelcomeMsg.SessionToken`](/docs/reference/protocol/welcome-msg#sessiontoken)). A token is an HS256 JWT over the session id, identity, display name and generation, signed with a key every gateway of the mesh shares (derived from the player signing key, so one configured secret covers both), which is what lets a client reconnect through *another* gateway and get the same session back. A token says nothing about whether the session still exists: that is the worker's [`PlayerSessions`](/docs/reference/protocol/player-sessions) to decide.
