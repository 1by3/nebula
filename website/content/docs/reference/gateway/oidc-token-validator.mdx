Checks OpenID Connect ID tokens against the issuers a mesh trusts ([`NebulaConfig.AuthIssuers`](/docs/reference/core/nebula-config#authissuers)): signature (RS256/384/512 and ES256/384/512 with the provider's published keys), issuer, expiry, and audience. Keys come from the issuer's discovery document and JWKS endpoint, fetched on a background thread and cached; a token with an unknown key id triggers one refresh (key rotation). [`Validate`](#validate) answers at once when the key is cached and otherwise once the fetch lands, always from [`Tick`](#tick) on the calling thread, so the gateway never blocks on the network.

| `audience` | Required `aud` (the client id the provider issued the game). Empty skips the check. |
| `fetch` | How discovery documents and key sets are downloaded; null uses HTTP. |
