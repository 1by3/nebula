Why a gateway holds a link to a worker. A link with no reason left is dropped after [`InterestSettings.LinkLingerSeconds`](/docs/reference/interest/interest-settings#linklingerseconds); the reasons are reported in [`GatewayStats.WorkerLinkReasons`](/docs/reference/control-plane/gateway-stats#workerlinkreasons) because "why am I talking to 40 workers" is the first question anyone asks of a mesh that is not scoping.
