Mesh-wide session ids. A gateway draws a random 32-bit incarnation when it starts and numbers its sessions from 1, so two gateways (or two starts of the same gateway) never hand out the same id without any coordination: `id = incarnation << 32 | sequence`. Workers key player state by this id, and it stays the same when the client reconnects through another gateway with its session token.
