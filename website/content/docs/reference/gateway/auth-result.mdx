The token's `iss` claim: the OpenID provider, or [`PlayerIdentity.AnonymousIssuer`](/docs/reference/gateway/player-identity#anonymousissuer) for a gateway-issued token.

### Subject [#subject]

```csharp
public string Subject;
```

The token's `sub` claim: the provider's user id.

### Error [#error]

```csharp
public string Error;
```

Why the token was rejected (empty when [`Ok`](#ok)).

### Claims [#claims]

```csharp
public Dictionary<string, object> Claims;
```

Every claim of the verified token, as parsed JSON (strings, doubles, booleans, lists and objects). Set only for a token verified against a trusted OpenID provider; null for a gateway-issued anonymous token. The gateway forwards the claims [`NebulaConfig.ForwardedClaims`](/docs/reference/core/nebula-config#forwardedclaims) names from here ([`PlayerClaims.Select`](/docs/reference/protocol/player-claims#select)).
