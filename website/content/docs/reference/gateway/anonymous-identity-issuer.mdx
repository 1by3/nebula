Identities the gateway hands to clients that present no token: an HS256 token with `iss` [`PlayerIdentity.AnonymousIssuer`](/docs/reference/gateway/player-identity#anonymousissuer) and a random `sub`, which the client keeps and presents on its next connection to get the same [`AuthResult.Identity`](/docs/reference/gateway/auth-result#identity) back. Every gateway of a mesh must use the same key (see [`NebulaConfig.AuthSigningKey`](/docs/reference/core/nebula-config#authsigningkey)).
