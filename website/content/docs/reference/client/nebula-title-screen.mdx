Optional IMGUI panel where a player enters the gateway address and a display name before connecting. Add it to the same GameObject as [`NebulaBootstrap`](/docs/reference/bootstrap/nebula-bootstrap); Nebula \> Set Up Active Scene adds it for you. Without it, a client started with no connection arguments stays idle until your own UI calls [`NebulaClient.ConnectTo`](/docs/reference/client/nebula-client#connectto). The panel stays hidden in processes without the client role and when `-nebula-gateway`, `-nebula-bot`, or `-nebula-connect` supplies the connection ([`NebulaClient.ConnectsAutomatically`](/docs/reference/client/nebula-client#connectsautomatically)). It hides once the local player spawns; press Escape to show it again. The entered values persist in PlayerPrefs.
