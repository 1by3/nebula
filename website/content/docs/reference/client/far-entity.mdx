An entity of the far relevance tier as a client sees it (NEB-388, `docs/interest-management.md` §16): a large or important entity beyond its normal relevance radius, with no replica, no variables and no RPCs, only enough to draw a marker or an impostor and to target it. Updated at the entity's far rate ([`UpdateRate`](#updaterate), 1 Hz by default); [`PredictedWorldPosition`](#predictedworldposition) extrapolates between updates.

[`Position`](#position) is absolute in the entity's scope and in double: the gateway sends it that way, so it is good to well under a millimetre at any distance a scope spans. [`WorldPosition`](#worldposition) is the same point in this client's Unity space (its floating origin taken off), which is what a marker is drawn at; it is in the scope's own space, outside every physics frame, so a ship standing on a turning planet is where the planet carries it.
