### Message [#message]

```csharp
public readonly string Message;
```

A readable description, the same text as [`NebulaClient.LastError`](/docs/reference/client/nebula-client#lasterror) when the client set one.

### WillRetry [#willretry]

```csharp
public readonly bool WillRetry;
```

True when the client keeps trying to connect; false when it has stopped and waits for [`NebulaClient.Connect`](/docs/reference/client/nebula-client#connect).

### Code [#code]

```csharp
public readonly ushort Code;
```

For [`DisconnectReason.Kicked`](/docs/reference/client/disconnect-reason#kicked): the code the server gave, a number of the game's own that Nebula passes through unchanged. 0 for every other reason, and when the server gave none.
