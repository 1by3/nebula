## Fields

### Fingerprint [#fingerprint]

```csharp
public string Fingerprint = "";
```

The SHA-256 of the gateway's SubjectPublicKeyInfo, as hex (colons and case are ignored). Empty accepts whatever certificate the gateway presents, which encrypts the link but does not authenticate the gateway; the client logs that once per connection.

### TimeoutSeconds [#timeoutseconds]

```csharp
public float TimeoutSeconds = 5f;
```

How long the client waits for the gateway's half of the handshake before giving up.
