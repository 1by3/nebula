## Fields

### Fingerprint [#fingerprint]

```csharp
public string Fingerprint = "";
```

SHA-256 hash of the gateway certificate's SubjectPublicKeyInfo, as hexadecimal text. Comparison ignores case and non-hexadecimal characters. An empty value accepts any certificate and logs a warning for each connection: traffic is encrypted, but the gateway's identity is not verified.

### TimeoutSeconds [#timeoutseconds]

```csharp
public float TimeoutSeconds = 5f;
```

Seconds the client waits for the gateway's handshake response before disconnecting.
