```csharp
public interface ITransport : IDisposable
```

Provides the network transport used by Nebula. Call [`Poll`](#poll) to receive events on the simulation thread. A transport can listen for incoming connections and connect to other processes, which lets a worker accept the gateway and worker peers while also connecting to peers.
