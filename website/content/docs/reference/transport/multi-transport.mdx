Several transports behind one [`ITransport`](/docs/reference/transport/i-transport), so the gateway accepts native clients over UDP and browsers over WebRTC without caring which link a peer arrived on. The first transport is the primary: [`Listen`](#listen), [`StartClient`](#startclient) and [`Connect`](#connect) go to it, and the others accept on ports of their own that were opened before they were added. A peer id is the inner id times the number of transports plus the transport's index.
