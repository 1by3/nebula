A transport that can tell, per peer, whether the link is encrypted. [`EncryptedTransport`](/docs/reference/transport/encrypted-transport), [`MultiTransport`](/docs/reference/transport/multi-transport) and the WebRTC transports implement it; the gateway asks it before it lets a client's `Hello` through when `NebulaConfig.RequireEncryption` is set.
