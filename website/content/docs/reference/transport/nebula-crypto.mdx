Provides random bytes, SHA-256 hashes, hash-based message authentication codes (HMAC), and key derivation for encrypted transport connections. Randomness, hashing, and HMAC use the platform's cryptography APIs.

The associated [`X25519`](/docs/reference/transport/x25519) and managed [`ChaCha20Poly1305Managed`](/docs/reference/transport/cha-cha20-poly1305-managed) implementations are not constant-time. The transport generates a new key pair for each connection.
