Implements ChaCha20-Poly1305 authenticated encryption with associated data (AEAD), as specified in RFC 8439. It uses a 32-byte key, a 12-byte nonce, and a 16-byte authentication tag. Ciphertext has the same length as plaintext; the tag adds 16 bytes. A nonce must not be reused with the same key.
