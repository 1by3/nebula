[`ISharedCacheClient`](/docs/reference/shared-cache/i-shared-cache-client) for a worker of a mesh or of Nebula Cloud: `GET` and `PUT` `/cache/{key}` on the orchestrator ([`SharedCacheHost`](/docs/reference/shared-cache/shared-cache-host)), over the same address and mesh token that [`RemotePersistenceStore`](/docs/reference/persistence/remote-persistence-store) uses. The body is the raw object. Both ends check it against the SHA-256 in the `X-Nebula-Checksum` header, and a mismatch is a miss on a read and a refused write.
