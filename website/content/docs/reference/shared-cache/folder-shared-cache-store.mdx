[`ISharedCacheStore`](/docs/reference/shared-cache/i-shared-cache-store) in a folder, one file per object. Used when the process is its own cache: the Editor (including Multiplayer Play Mode), a single-process run, and an orchestrator that keeps its data in files.

A file is named after the hash of its key, so any valid key is a safe file name on every platform and keys that differ only by letter case do not collide. It holds the key, the checksum and the bytes. An object is written to a temporary file in the same folder and then moved into place, so a reader never sees a half-written file and two processes that write the same key at once both succeed. The file's last-write time is the entry's last-read time: nothing else rewrites a finished file.
