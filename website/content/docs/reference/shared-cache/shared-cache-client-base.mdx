What every client does around a backend call. Both calls do their work on the thread pool, so the task completes off the Unity main thread and the call returns before any disk or network work starts. A client lets at most `maxConcurrent` calls run at once (the rest wait), gives each call [`Timeout`](#timeout) to finish, backs off for a few seconds after a failure so a stopped orchestrator does not make every call wait out its timeout, and writes one log line per call.
