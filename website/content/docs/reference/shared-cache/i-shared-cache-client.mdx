A worker's way to the shared cache. [`NebulaSharedCache`](/docs/reference/shared-cache/nebula-shared-cache) holds the one a process uses; the bootstrap installs [`LocalSharedCacheClient`](/docs/reference/shared-cache/local-shared-cache-client) or [`RemoteSharedCacheClient`](/docs/reference/shared-cache/remote-shared-cache-client).
