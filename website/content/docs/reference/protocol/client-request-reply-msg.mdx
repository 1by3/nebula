What became of a client request that asked for a reply ([`MsgId.ClientRequestReply`](/docs/reference/protocol/msg-id#clientrequestreply), protocol 32). A worker sends it to the gateway that sent the request, which finds the client by [`ClientId`](#clientid) and passes it on; a gateway that drops a request sends it to the client directly. Two bytes of verdict at most: [`Code`](#code) is the handler's own.
