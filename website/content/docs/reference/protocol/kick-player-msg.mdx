Worker -\> gateway: remove this player ([`MsgId.KickPlayer`](/docs/reference/protocol/msg-id#kickplayer), protocol 23), sent by `NebulaWorker.Kick` to the gateway that speaks for the session. The gateway sends the client a [`KickedMsg`](/docs/reference/protocol/kicked-msg) with the same code and reason, closes the link and ends the session. Fenced by [`Generation`](#generation): a gateway that has since claimed the session with a newer generation ignores it.
