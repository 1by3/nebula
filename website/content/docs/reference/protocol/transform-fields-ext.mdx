Protocol 30 additions to a root transform update, in a byte written after [`TransformFields`](/docs/reference/protocol/transform-fields) to peers of [`HelloMsg.MotionFidelityVersion`](/docs/reference/protocol/hello-msg#motionfidelityversion) or newer. An older client is sent neither the byte nor what it announces.
