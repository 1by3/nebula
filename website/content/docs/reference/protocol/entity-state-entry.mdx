### WireSize [#wiresize]

```csharp
public const int WireSize = 8 + 4 + ContainerRef.MaxWireSize + 2 + 12 + 16 + 12 + 6;
```

Largest serialized size of one entry, for sizing Sequenced batches: id, epoch, container reference (two bytes for a static container, ten for a dynamic one), field mask, position, rotation, scale, and velocity. Only selected axes are serialized. Position, rotation, and scale precision follows NetworkTransform; velocity uses three half floats when enabled.
