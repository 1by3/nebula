## Fields

### WireSize [#wiresize]

```csharp
public const int WireSize = 8 + 4 + ContainerRef.MaxWireSize + 2 + 1 + 12 + 16 + 12 + 6 + 6;
```

Largest serialized size of one entry, for sizing Sequenced batches: id, epoch, container reference (two bytes for a static container, ten for a dynamic one), field mask, extension byte, position, rotation, scale, velocity and angular velocity. Only selected axes are serialized. Position, rotation, and scale precision follows NetworkTransform; velocity and angular velocity use three half floats when enabled.
