### WireSize [#wiresize]

```csharp
public const int WireSize = 8 + 4 + ContainerRef.MaxWireSize + 12 + 4 + 6;
```

Largest serialized size of one entry, for sizing Sequenced batches: id, epoch, container reference (two bytes for a static container, ten for a dynamic one), position (3 floats), rotation (smallest-three, 4 bytes) and velocity (3 halves). Rotation and velocity are the two fields that tolerate compression: a pawn's yaw to a hundredth of a degree and its speed to three decimals.
