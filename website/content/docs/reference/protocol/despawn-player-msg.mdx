Gateway -\> worker: the client's link ended, so the session waits for a reclaim, or the session is over ([`EndNow`](#endnow)). Fenced by [`Generation`](#generation) like [`SpawnPlayerMsg`](/docs/reference/protocol/spawn-player-msg). A worker that has handed the pawn on forwards it to the new owner.

### EndNow [#endnow]

```csharp
public bool EndNow;
```

The session is over and not waiting for a reclaim: the player said goodbye, or was kicked. The worker removes the pawn now instead of keeping it for [`NebulaConfig.SessionReclaimSeconds`](/docs/reference/core/nebula-config#sessionreclaimseconds). A trailing optional field (protocol 22), written only when set.
