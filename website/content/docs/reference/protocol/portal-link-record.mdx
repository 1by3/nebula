One party's link through a portal, as the network gateway and a client learn it ([`MsgId.PortalLinks`](/docs/reference/protocol/msg-id#portallinks)). Toward the network gateway it carries the members and the observers; toward a client both lists are empty and [`Flags`](#flags) says whether this client is a member and whether it is an observer.
