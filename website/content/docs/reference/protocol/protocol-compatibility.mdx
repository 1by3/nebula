The deployment compatibility rules, in one place so the gateway, the tests and a game's own tooling all answer the same way. Design record: `docs/compatibility-policy.md`; version table: `docs/protocol-versions.md`.

Client to gateway accepts a window of protocol versions ([`HelloMsg.MinProtocolVersion`](/docs/reference/protocol/hello-msg#minprotocolversion)..[`HelloMsg.ProtocolVersion`](/docs/reference/protocol/hello-msg#protocolversion), N-1 and N). Gateway to worker and worker to worker require [`HelloMsg.ProtocolVersion`](/docs/reference/protocol/hello-msg#protocolversion) exactly, because those processes are upgraded together by the operator and a half-upgraded mesh has no client to keep happy.

The oldest game content version a gateway configured with `server` and `configuredMin` admits: the server's own number when no minimum is configured, which makes the default an exact match.
