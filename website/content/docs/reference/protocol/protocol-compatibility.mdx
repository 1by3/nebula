Checks client protocol and game content versions against the gateway's supported range.

The window is [`HelloMsg.MinProtocolVersion`](/docs/reference/protocol/hello-msg#minprotocolversion) to [`HelloMsg.ProtocolVersion`](/docs/reference/protocol/hello-msg#protocolversion), narrowed to [`HelloMsg.TickRateVersion`](/docs/reference/protocol/hello-msg#tickrateversion) and up on a mesh that does not run at the default tick rate ([`MinClientProtocol`](#minclientprotocol)). Gateway-to-worker and worker-to-worker connections require [`HelloMsg.ProtocolVersion`](/docs/reference/protocol/hello-msg#protocolversion) exactly.

Returns whether the client's protocol is within the gateway's inclusive supported range.

### MinClientProtocol [#minclientprotocol]

```csharp
public static ushort MinClientProtocol(int tickRate);
```

The oldest client protocol a gateway whose mesh runs at `tickRate` admits: the window's minimum at the default rate, and [`HelloMsg.TickRateVersion`](/docs/reference/protocol/hello-msg#tickrateversion) at any other, because an older client would count every tick at 60 Hz.

### MinContentVersion [#mincontentversion]

```csharp
public static uint MinContentVersion(uint server, uint configuredMin);
```

Returns the minimum accepted content version. A zero minimum or one greater than `server` uses the server's version, requiring an exact match.

### ContentVersionAccepted [#contentversionaccepted]

```csharp
public static bool ContentVersionAccepted(uint client, uint server, uint configuredMin);
```

Returns whether the client's content version is within the configured inclusive range. A `server` value of zero accepts every content version.
