The sender's side of the reply channel: the requests a client made with a reply wanted and has not heard back about. Each settles exactly once, with the reply that arrives, with [`ClientRequestOutcome.TimedOut`](/docs/reference/protocol/client-request-outcome#timedout) when [`Expire`](#expire) passes its deadline, or with [`ClientRequestOutcome.Disconnected`](/docs/reference/protocol/client-request-outcome#disconnected) from [`FailAll`](#failall).
