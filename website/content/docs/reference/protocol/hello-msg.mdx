### MinProtocolVersion [#minprotocolversion]

```csharp
public const ushort MinProtocolVersion = 18;
```

The oldest protocol a gateway of this build accepts from a **client**: **N-1**, or N while the policy has no older version to admit yet. Gateway-to-worker and worker-to-worker links ignore it and require [`ProtocolVersion`](#protocolversion) exactly. See `docs/compatibility-policy.md`.

To bump the protocol: raise [`ProtocolVersion`](#protocolversion) to the new number and set this to the previous one, so the gateway keeps admitting clients of the build that is being replaced. Never widen it past one version, and never make a change inside the window that is not additive (a new message, or a trailing optional field gated on the negotiated version).

### Token [#token]

```csharp
public string Token;
```

Client only: the token that says who the player is. An OpenID Connect ID token from a provider the mesh trusts ([`NebulaConfig.AuthIssuers`](/docs/reference/core/nebula-config#authissuers)), the token a gateway issued in an earlier [`WelcomeMsg`](/docs/reference/protocol/welcome-msg), or empty to ask for a new anonymous identity. For a gateway or worker peer it is the infrastructure credential instead ([`MeshPeerAuth`](/docs/reference/gateway/mesh-peer-auth)), proving the peer holds the mesh token.

### Incarnation [#incarnation]

```csharp
public uint Incarnation;
```

Gateway and worker peers: a number that changes every time the process starts, so a peer that sees the same id twice can tell a restart from a reconnect. Clients send 0.

### ScopeKey [#scopekey]

```csharp
public string ScopeKey;
```

Client only: the simulation scope to be placed in, as an opaque key ([`EntityLocation.ScopeKey`](/docs/reference/containers/entity-location#scopekey)). Empty is the public world, which is what every client sent before this field existed. The gateway spawns the player only into containers of that scope, and holds the join while the scope is not ready (`docs/scope-activation.md` §5). It does not activate the scope: whoever sent the player to the key is the one that called [`IControlPlane.ActivateScope`](/docs/reference/control-plane/i-control-plane#activatescope).

### Version [#version]

The protocol this peer speaks. 0 on a message that was built rather than read, which [`Write`](#write) sends as [`ProtocolVersion`](#protocolversion); set it to announce an older one (what the compatibility tests do to play a client of the previous build).

### GameContentVersion [#gamecontentversion]

```csharp
public uint GameContentVersion;
```

Client only: the version of the game's own content and rules this build carries, declared by the game ([`NebulaConfig.GameContentVersion`](/docs/reference/core/nebula-config#gamecontentversion), `-nebula-content-version`). Nebula does not interpret it: the gateway compares it with its own configured window and refuses a client outside it with [`JoinRejectReason.ContentVersionMismatch`](/docs/reference/protocol/join-reject-reason#contentversionmismatch). 0 means the game does not version its content, and every gateway that does not either will accept it.
