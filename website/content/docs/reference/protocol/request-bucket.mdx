A client's token bucket: `burst` requests at once, refilled at `rate` per second. A plain struct so a gateway keeps one in every client's record and one per entity without allocating.

## Methods

### TryTake [#trytake]

```csharp
public bool TryTake(double now, double rate, double burst);
```

Take one token at time `now`. A `rate` of zero or less is "no limit" and always succeeds. A `burst` under 1 is treated as 1.

### IsIdle [#isidle]

```csharp
public bool IsIdle(double now, double rate, double burst, double idleSeconds);
```

Whether the bucket would be full again at `now`: nothing to remember about it.
