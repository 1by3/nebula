Where a `[ClientRequestRpc]` call ended up. A caller that asked for a reply (`NetworkBehaviour.ClientRequestWithReply`) receives exactly one of these; a fire-and-forget request is decided by the same rules and only logs a rejection where it is decided. The rejections up to `HopLimit` travel on the wire; `TimedOut` and `Disconnected` are decided on the client and never sent.
