```csharp
public enum JoinRejectReason : byte
```

Why a join was refused, in typed form. A reason string is for the player; this is for the game's client code, which has to tell "your token is bad" (pointless to retry) from "that station is full" (try a queue, another instance, or later). See `docs/capacity-admission.md`.
