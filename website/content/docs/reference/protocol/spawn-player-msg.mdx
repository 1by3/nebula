Gateway -\> worker: a client wants a pawn. Doubles as the claim of a session by a gateway: a worker that already holds a pawn for [`ClientId`](#clientid) re-announces it to the sender and, when [`Generation`](#generation) is newer than the one it knew, routes the session through the sender from now on ([`PlayerSessions`](/docs/reference/protocol/player-sessions)).

### Generation [#generation]

```csharp

```

The session's connection generation: increases every time a client (re)claims the session. A worker ignores a claim or a despawn carrying an older generation than the one it holds, which fences a gateway that lost the client from undoing what the gateway that gained it did.
