What one [`MsgId.ContainerOwnership`](/docs/reference/protocol/msg-id#containerownership) message says: either the complete set of containers a client should know about ([`Full`](#full)) or a change to it. Interest management makes this per-client and incremental (design §8): a client is told about the containers overlapping its own window, so the snapshot of a large world is no longer broadcast to everybody.
