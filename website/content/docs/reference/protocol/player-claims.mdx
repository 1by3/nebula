Claims from a player's verified sign-in token that the gateway forwards to workers ([`NebulaConfig.ForwardedClaims`](/docs/reference/core/nebula-config#forwardedclaims)): the claim names the game listed, with their values as strings. Workers read them through [`NetworkIdentity.OwnerClaims`](/docs/reference/core/network-identity#ownerclaims), [`PlayerInfo.Claims`](/docs/reference/core/player-info#claims) and [`NebulaWorker.GetPlayerClaims`](/docs/reference/worker/nebula-worker#getplayerclaims). This class holds the limits, the selection from a token and the wire codec.

Only claims from a token the gateway verified against a trusted OpenID provider are forwarded. Anonymous players, whose tokens the gateway issued itself, have none. Claims never reach clients.

Split a comma- or space-separated list of claim names ([`NebulaConfig.ForwardedClaims`](/docs/reference/core/nebula-config#forwardedclaims)). Duplicates, names longer than [`MaxNameLength`](#maxnamelength) and names past [`MaxCount`](#maxcount) are left out.

### Select [#select]

```csharp
public static IReadOnlyDictionary<string, string> Select(Dictionary<string, object> payload, IReadOnlyList<string> names, List<string> dropped = null);
```

The claims named in `names`, from a verified token's `payload`. Strings are copied as they are; numbers and booleans are formatted the way [`JsonWebToken.Claim`](/docs/reference/gateway/json-web-token#claim) formats them. A claim that is missing, null, an array or an object, or longer than [`MaxValueLength`](#maxvaluelength), is left out. `dropped` lists the names that were present but left out, for a log line.
