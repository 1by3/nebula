A `[ClientRequestRpc]` as the client sends it to its gateway ([`MsgId.ClientRequest`](/docs/reference/protocol/msg-id#clientrequest), protocol 33). It says nothing about who sent it: the gateway knows that from the connection, and what it forwards is a [`ClientRequestRoutedMsg`](/docs/reference/protocol/client-request-routed-msg) it built itself. Everything in it is untrusted.
