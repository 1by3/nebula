### Token [#token]

```csharp
public string Token;
```

Set when the client presented no token: the anonymous token the gateway issued for [`Identity`](#identity). The client keeps it and presents it in its next [`HelloMsg`](/docs/reference/protocol/hello-msg) to be the same player again. Empty when the client's own token was accepted.

### SessionToken [#sessiontoken]

```csharp
public string SessionToken;
```

A signed token naming this session ([`SessionTokens`](/docs/reference/gateway/session-tokens)). The client keeps it for the life of the process and presents it in [`HelloMsg.Session`](/docs/reference/protocol/hello-msg#session) when it reconnects, to any gateway of the mesh, to get the same [`ClientId`](#clientid) and pawn back.

### Reclaimed [#reclaimed]

```csharp
public bool Reclaimed;
```

True when the session was reclaimed from a token: the pawn, when the worker still holds it, is the same one.

### NegotiatedVersion [#negotiatedversion]

```csharp
public ushort NegotiatedVersion;
```

The protocol the gateway settled on for this session: the version the client announced in its [`HelloMsg`](/docs/reference/protocol/hello-msg), which is somewhere in the gateway's window. The gateway encodes everything it sends this client at that version; the client may use it to tell which optional fields to expect. 0 from a gateway that does not write it (assume [`HelloMsg.ProtocolVersion`](/docs/reference/protocol/hello-msg#protocolversion)).
