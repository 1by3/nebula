Gateway -\> worker: the set of regions this gateway wants entities from. The state is a set, so the message is idempotent: a delta applies only when [`BaseSeq`](#baseseq) is the worker's current sequence and the resulting (count, hash) matches, and the worker otherwise keeps what it has and asks for a resync. The grid travels with it so a worker can refuse to filter with ids the gateway did not mean.
