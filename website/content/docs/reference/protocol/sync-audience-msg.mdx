Worker to gateway ([`MsgId.SyncAudience`](/docs/reference/protocol/msg-id#syncaudience), protocol 20): the member sets of an entity's [`SyncAudience.Custom`](/docs/reference/core/sync-audience#custom) behaviors changed. Sent reliably, before that tick's sync chunks, to every gateway the entity's sync state goes to. It carries every set whole rather than a delta, so applying it twice does no harm. The gateway sends each client that joined a set the newest keyframe it holds, and tells each client that left to drop its copy ([`SyncStateCodec.ChunkFlags.Cleared`](/docs/reference/core/sync-state-codec#cleared)).
