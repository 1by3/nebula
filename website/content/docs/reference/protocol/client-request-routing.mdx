The rule a worker applies to a routed client request, with no engine types. The gateway sends a request to the worker it believes owns the entity; after a handover that worker holds a ghost and passes the request on, at most `maxHops` times ([`NebulaConfig.AuthorityCallMaxHops`](/docs/reference/core/nebula-config#authoritycallmaxhops)), exactly as an `AuthorityRpc` is.

| Parameter | Description |
| --- | --- |
| `known` | This worker holds a copy of the entity (authoritative or ghost). |
| `hasAuthority` | This worker has authority over it. |
| `canForward` | There is a connected worker to pass the request to, other than the sender. |
| `hops` | How many workers have forwarded the request before this one. |
| `maxHops` | The forwards allowed. |
