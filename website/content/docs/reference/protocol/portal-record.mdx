A portal as the network gateway and a client learn it ([`MsgId.Portals`](/docs/reference/protocol/msg-id#portals), protocol 28): the near face, the far side, the aperture and the sizes of the regions derived from it. The record is the portal's definition only; the state of each party's link travels separately ([`PortalLinkRecord`](/docs/reference/protocol/portal-link-record)).

### FarOrigin [#farorigin]

```csharp
public Double3 FarOrigin;
```

The far face, absolute in the far scope. A template's far face is the near face's origin read in the instance's own upright space, with the identity rotation, or the near face's when the portal does not turn with its face (`docs/portals.md` D5), so it is the same for every party's far scope and the network gateway can place the far window without a link's help (D21).
