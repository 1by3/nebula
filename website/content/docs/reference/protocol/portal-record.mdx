A portal as the network gateway and a client learn it ([`MsgId.Portals`](/docs/reference/protocol/msg-id#portals), protocol 28): the near face, the far side, the aperture and the sizes of the regions derived from it. The record is the portal's definition only; the state of each party's link travels separately ([`PortalLinkRecord`](/docs/reference/protocol/portal-link-record)).
