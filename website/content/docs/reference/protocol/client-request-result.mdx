### Code [#code]

```csharp
public ushort Code { get; }
```

A number the handler chose, through [`ClientRequestContext.ReplyCode`](/docs/reference/core/client-request-context#replycode): its own verdict ("allowed", "too far", "not yours"). 0 unless the handler set one and [`Outcome`](#outcome) is [`ClientRequestOutcome.Accepted`](/docs/reference/protocol/client-request-outcome#accepted). Not a place for data: the reply is two bytes of verdict, and a handler that needs to answer with more sends a `ClientRpc` or an owner call.

### Succeeded [#succeeded]

```csharp
public bool Succeeded { get; }
```
