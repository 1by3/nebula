One side's window of a portal (`docs/portals.md` D3, D20): the cross-section of the aperture grown by the portal's `WindowMargin` sideways and extruded `WindowDepth` into that side, an oriented box in the face's axes. The near side's window is the part of the face's axes with z \< 0, the far side's the part with z ≥ 0 (D2). Pure geometry, in double, built from a [`PortalRecord`](/docs/reference/protocol/portal-record) alone so the network gateway, which runs no game code, can decide who may look through a link (D21) and a client can learn what it was sent.
