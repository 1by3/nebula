An `AuthorityRpc` on the worker-to-worker link ([`MsgId.AuthorityRpc`](/docs/reference/protocol/msg-id#authorityrpc)). Beside the fields an [`EntityRpcMsg`](/docs/reference/protocol/entity-rpc-msg) carries, it names the call ([`CallId`](#callid), minted by the sender: see [`AuthorityCallId`](/docs/reference/worker/authority-call-id)), counts the forwards it has taken ([`Hops`](#hops)) and says whether the sender wants to hear the outcome. The contract is in `docs/cross-worker-calls.md`.
