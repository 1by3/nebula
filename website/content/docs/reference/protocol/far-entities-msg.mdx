Worker -\> gateway, and gateway -\> client: a batch of far-tier entries ([`MsgId.FarEntities`](/docs/reference/protocol/msg-id#farentities), protocol 26). `[id][count:ushort]{entry}`. A worker sends it at each entity's far rate to the gateways whose foci are within the entity's far radius; a gateway relays to each client the entries of the entities in that client's far tier, and only to clients that negotiated protocol 26 or later.
