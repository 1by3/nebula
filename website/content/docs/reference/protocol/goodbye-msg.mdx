Client -\> gateway: the player is leaving for good ([`MsgId.Goodbye`](/docs/reference/protocol/msg-id#goodbye), protocol 22). No body. The gateway ends the session at once, without the reclaim grace, and closes the link; that close is how the client knows the goodbye arrived.
