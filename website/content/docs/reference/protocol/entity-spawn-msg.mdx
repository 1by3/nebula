Full description of an entity. Sent as EntitySpawn (to gateway/clients), GhostSpawn (to a neighbor worker) and as the payload of AuthorityTransfer. Receivers treat a spawn for a known netId as an update (owner/epoch/container/vars), never as a duplicate instantiation.

### CohesionGroup [#cohesiongroup]

```csharp
public uint CohesionGroup;
```

The entity's cohesion group ([`NetworkIdentity.CohesionGroup`](/docs/reference/core/network-identity#cohesiongroup)), 0 for none. It travels with every spawn, ghost spawn and handover, so each worker holding a copy knows which group the entity is in and a handover of any member can take the rest with it (protocol 18, `docs/cohesion-hints.md`).

### CostWeight [#costweight]

```csharp
public float CostWeight;
```

What the game says this entity costs to simulate, as a multiplier on its category weight ([`NetworkIdentity.EffectiveCostWeight`](/docs/reference/core/network-identity#effectivecostweight), protocol 18). It travels with the entity so the worker it lands on reports the same cost for it. Sent as an f16; zero is a valid weight. A missing field reads as -1, which leaves the receiver's current weight unchanged.

### AudienceGeneration [#audiencegeneration]

```csharp
public uint AudienceGeneration;
```

Worker to gateway and worker to worker: the entity's audience generation ([`NetworkIdentity.SyncAudienceGeneration`](/docs/reference/core/network-identity#syncaudiencegeneration)), raised every time a [`SyncAudience.Custom`](/docs/reference/core/sync-audience#custom) member set changes. It travels with the entity through ghosting and handover, so it never goes back, and a gateway holds back a restricted chunk stamped with a newer generation than the member sets it has (protocol 20, trailing and optional, written only when it or [`Audience`](#audience) is set). A gateway never forwards it to a client.

### Audience [#audience]

```csharp
public byte[] Audience;
```

Worker to gateway and worker to worker: the member sets of the entity's Custom behaviors ([`SyncAudienceCodec`](/docs/reference/core/sync-audience-codec)), or null when it has none. A gateway never forwards it to a client.

### Maps [#maps]

```csharp
public byte[] Maps;
```

Every [`NetworkMap<TKey, TValue>`](/docs/reference/core/network-map) of the entity in full (a [`NetworkMapCodec`](/docs/reference/protocol/network-map-codec) section), or null when it has none (protocol 21, trailing and optional, docs/replicated-collections.md D5). A gateway keeps it current with each [`MsgId.EntityMaps`](/docs/reference/protocol/msg-id#entitymaps) and hands it to a late joiner.
