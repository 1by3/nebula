A client request stamped by the gateway ([`MsgId.ClientRequestRouted`](/docs/reference/protocol/msg-id#clientrequestrouted), protocol 32): the request as the client sent it, beside who the gateway knows the sender to be. The stamp is the gateway's, never the client's: it is built from the connection, and a worker accepts it only from a gateway or a worker of the mesh. The worker with authority over the entity decodes it and hands the handler a [`ClientRequestContext`](/docs/reference/core/client-request-context).
