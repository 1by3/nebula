A driver's recent inputs for an entity it drives ([`MsgId.DriveInput`](/docs/reference/protocol/msg-id#driveinput), protocol 25): the same frames as [`ClientInputMsg`](/docs/reference/protocol/client-input-msg), for the entity [`NetId`](#netid) names instead of the sender's pawn. The client sends 0 as [`ClientId`](#clientid); the gateway stamps the sender's before forwarding.
