The wire and save format of [`NetworkMapBase`](/docs/reference/core/network-map-base) contents (docs/replicated-collections.md D3). Keys and values are opaque, length-prefixed bytes, so a party with no game types (the gateway) can keep a map's contents and hand a late joiner a full copy.

```csharp
body    = [version:byte=1][flags:byte (1 = clear first)][count:int] { [op:byte (0 remove, 1 set)][keyLen:ushort][key]([valueLen:ushort][value]) }
section = [mapCount:byte] { [mapIndex:byte][bodyLength:int][body] }
```

A full copy is a body with the clear flag set and every entry as a set. A delta is a body with only the keys that changed, each with its final state, so applying it to a copy that already contains it changes nothing.
