Where a worker's tick goes. Nebula times each phase of its own tick; game code may add sections of its own (`static readonly ProfileSection Move = NebulaProfiler.Section("npc.move")`) and they appear in the same report: one `[nebula] profile` log line per [`NebulaWorker`](/docs/reference/worker/nebula-worker) every few seconds, with every section's cost expressed in milliseconds per simulated tick so the columns add up to the tick time.
