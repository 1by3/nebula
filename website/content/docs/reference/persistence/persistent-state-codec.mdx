The state blob of a [`PersistedEntityRecord`](/docs/reference/persistence/persisted-entity-record): every [`PersistAttribute`](/docs/reference/persistence/persist-attribute) NetworkVariable and every behaviour's [`NetworkBehaviour.WritePersistentState`](/docs/reference/core/network-behaviour#writepersistentstate) chunk, each under a name.

Named entries rather than a positional layout, because a save outlives the build that wrote it: a variable that was removed is skipped on read, one that was added keeps its default, and a renamed behaviour simply starts fresh. Each entry is length-prefixed and read through a reader bounded to its own bytes, so a behaviour that reads too much fails inside its chunk (logged) instead of corrupting the next entry.

```csharp
[version:byte=1][count:ushort] { [name:string][length:ushort][bytes] }
```

Pure functions over a [`NetworkIdentity`](/docs/reference/core/network-identity): no worker, no store, no scene.

Apply a blob to `identity`. Entries are matched by name: unknown ones are skipped and missing ones leave the entity's own defaults. Reading a variable fires its `OnValueChanged`, which is what a restored entity wants.
