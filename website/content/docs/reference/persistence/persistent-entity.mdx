Put this on a prefab or a scene object to make the entity outlive the process that simulates it. The worker's [`NebulaPersistence`](/docs/reference/persistence/nebula-persistence) checkpoints every authoritative entity that carries one, and brings it back when a worker gains the lease of the container it was saved in.

What is saved: the entity's prefab (or scene id), its pose in its container, every [`PersistAttribute`](/docs/reference/persistence/persist-attribute) NetworkVariable and whatever each behaviour writes in [`NetworkBehaviour.WritePersistentState`](/docs/reference/core/network-behaviour#writepersistentstate) (see [`PersistentStateCodec`](/docs/reference/persistence/persistent-state-codec)). What identifies it across runs and workers is [`Key`](#key), which travels with the entity through handover, so a save written by one worker is the same record the next worker updates.

Saves the entity's extent when it was set at runtime ([`NetworkIdentity.ExtentChangedAtRuntime`](/docs/reference/core/network-identity#extentchangedatruntime)), so a structure edited since it spawned comes back measured by its edited box (`docs/entity-extents.md` D7).
