```csharp
public sealed class PersistedEntityRecord
```

One persisted entity as the store holds it: enough to bring the entity back on any worker (prefab or scene object, container and pose, authority epoch) plus the opaque state blob the entity itself wrote ([`PersistentStateCodec`](/docs/reference/persistence/persistent-state-codec): opted-in NetworkVariables and behaviour state, keyed by name). Plain data on purpose: nothing here depends on the storage backend.
