[`PersistedEntityRecord`](/docs/reference/persistence/persisted-entity-record) as JSON, the wire format between [`RemotePersistenceStore`](/docs/reference/persistence/remote-persistence-store) (workers) and [`PersistenceHost`](/docs/reference/persistence/persistence-host) (the orchestrator). The state blob travels base64-encoded; vectors are `[x, y, z]`, the rotation `[x, y, z, w]`, times Unix milliseconds.
