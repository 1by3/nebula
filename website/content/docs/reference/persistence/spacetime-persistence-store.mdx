[`IPersistenceStore`](/docs/reference/persistence/i-persistence-store) over the Nebula persistence SpacetimeDB module (SpacetimeDB/PersistenceModule~), a database of its own next to the control plane.

Mirrors the whole `persisted_entity` table into a dictionary and answers every load from that mirror, so a restore never waits on a round trip. Writes go through reducers (the module holds the epoch rule). Saves issued while disconnected are queued (the latest one per key wins) and flushed on connect, and the connection retries every 2 s. Like [`SpacetimeControlPlane`](/docs/reference/control-plane/spacetime-control-plane) the connection is pumped from [`Tick`](#tick), so every callback the caller gets lands on the main thread.
