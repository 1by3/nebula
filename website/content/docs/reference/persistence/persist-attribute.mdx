Marks a [`NetworkVariable<T>`](/docs/reference/core/network-variable) field as part of the entity's saved state. The variable is written into the persistence blob under its discovered name (`"<BehaviourTypeName>.<FieldName>"`) and assigning it also schedules the entity's next checkpoint, so a saved value is never more than a checkpoint behind what the simulation holds.

```csharp
public sealed class Door : NetworkBehaviour
{
    [Persist] public NetworkVariable<bool> IsOpen = new NetworkVariable<bool>();
}
```

The entity itself opts in by carrying a [`PersistentEntity`](/docs/reference/persistence/persistent-entity); without one, a [`PersistAttribute`](/docs/reference/persistence/persist-attribute) has no effect.
