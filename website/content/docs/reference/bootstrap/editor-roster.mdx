What one virtual player knows about the others of the Multiplayer Play Mode window, read from the project's `Library/VP/SystemData.json` ([`EditorRosterReader`](/docs/reference/bootstrap/editor-roster-reader)). [`EditorRunPlan.Resolve`](/docs/reference/bootstrap/editor-run-plan#resolve) uses it so that exactly one virtual player hosts the server: an untagged virtual player hosts only when it is the active one with the lowest index, and every other one is a client.

## Methods

### Parse [#parse]

```csharp
public static EditorRoster Parse(string json, string playerFolder, out string problem);
```

Work out the roster facts for the virtual player that runs from `Library/VP/<playerFolder>` (the folder is the player's `m_Prefix` followed by its `m_Id`) from the text of `SystemData.json`. Tolerant: anything unreadable gives [`Unknown`](#unknown) and a reason in `problem`; null when the roster was read.
