Binds the clients of the Multiplayer Play Mode dev loop to the server their own session started, so a client never joins some other mesh that happens to hold the port. The server writes `Library/Nebula/dev-session.json` once its gateway and worker have bound their ports, or failed to, and deletes it when it stops. A client waits for the file, connects to the port it names while the process that wrote it is alive, and refuses with the server's reason when the server could not start.
