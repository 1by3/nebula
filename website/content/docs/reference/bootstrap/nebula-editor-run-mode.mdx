What pressing Play in the Editor starts ([`NebulaConfig.EditorRunMode`](/docs/reference/core/nebula-config#editorrunmode)). Builds are never affected.

## Members

| Name | Value | Description |
| --- | --- | --- |

| <span id="multiplayerplaymode"></span>`MultiplayerPlayMode` | `1` | No build: a Multiplayer Play Mode virtual player hosts the whole server in its own Editor process (orchestrator, gateway and one worker, with the control plane in memory), and the main Editor is a client that connects to it.
