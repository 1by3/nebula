Use the `nebula` command-line tool to add Nebula to a Unity project, run a local mesh, and deploy it. To read the same help in a terminal, run `nebula --help` or `nebula <command> --help`. See [Install the CLI](/docs/getting-started/install) before you begin.

```bash
nebula <command> [options]
```

## Getting started

| Command | Summary |
| --- | --- |
| [nebula setup](/docs/cli/setup) | Install the prerequisites for running Nebula locally |
| [nebula init](/docs/cli/init) | Install Nebula into the Unity project in the current folder |

## Running locally

| Command | Summary |
| --- | --- |
| [nebula build](/docs/cli/build) | Build the Unity player and standalone .NET services |
| [nebula start](/docs/cli/start) | Start the orchestrator, gateway, and workers on this computer |
| [nebula stop](/docs/cli/stop) | Stop the local mesh (every process of the build) |
| [nebula status](/docs/cli/status) | Show workers, containers, entity counts, persistence, and recent events |
| [nebula logs](/docs/cli/logs) | Read the log for the orchestrator, gateway, a worker, or a bot client |
| [nebula scale](/docs/cli/scale) | Change the worker range of the running mesh |
| [nebula dashboard](/docs/cli/dashboard) | Open the Nebula Dashboard of the local mesh or the deployed one |

## Deploy

| Command | Summary |
| --- | --- |
| [nebula config](/docs/cli/config) | Configure a deploy target, the deployed mesh's database, or the Unity editor path |
| [nebula deploy](/docs/cli/deploy) | Build and deploy the mesh to Nebula Cloud or your own Hetzner project |
| [nebula destroy](/docs/cli/destroy) | Delete the deployed mesh |

## Nebula Cloud

| Command | Summary |
| --- | --- |
| [nebula cloud](/docs/cli/cloud) | Log in to Nebula Cloud, log out, or show your account |
| [nebula deployments](/docs/cli/deployments) | List the Nebula Cloud deployments of the project's organization |
| [nebula rollback](/docs/cli/rollback) | Roll a Nebula Cloud deployment back to its previous release |

## Other

| Command | Summary |
| --- | --- |
| [nebula version](/docs/cli/version) | Print the CLI version |
| [nebula help](/docs/cli/help) | Show help for the CLI or one command |

## Global options

| Option | Description |
| --- | --- |
| `--project <path>` | Run against another Nebula project instead of the current folder. |
| `-v, --verbose` | Print stack traces and the commands the CLI runs. |
| `-y, --yes` | Answer every confirmation with yes. |
