---
title: "nebula destroy"
description: "Delete the mesh's cloud servers"
---

To delete the mesh's cloud servers, run:

```bash
nebula destroy [--all]
```

Delete every server labelled with the mesh (orchestrator and workers). A SQLite database on the orchestrator VM goes with it, and with it every saved entity; a PostgreSQL database is left untouched.

## Options

| Option | Description |
| --- | --- |
| `--all` | Also delete the firewalls, private network, and SSH key. |

## Global options

These work with every command and may appear before or after it.

| Option | Description |
| --- | --- |
| `--project <path>` | Run against another Nebula project instead of the current folder. |
| `-v, --verbose` | Print stack traces and the commands the CLI runs. |
| `-y, --yes` | Answer every confirmation with yes. |
