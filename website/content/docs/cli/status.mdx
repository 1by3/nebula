---
title: "nebula status"
description: "Show workers, containers, entity counts, and recent events"
---

To show workers, containers, entity counts, and recent events, run:

```bash
nebula status [--cloud]
```

## Options

| Option | Description |
| --- | --- |
| `--cloud` | The deployed mesh (Hetzner servers + its Nebula Dashboard) instead of the local one. |
| `--json` | Print the raw /api/state JSON. |

## Global options

These work with every command and may appear before or after it.

| Option | Description |
| --- | --- |
| `--project <path>` | Run against another Nebula project instead of the current folder. |
| `-v, --verbose` | Print stack traces and the commands the CLI runs. |
| `-y, --yes` | Answer every confirmation with yes. |
