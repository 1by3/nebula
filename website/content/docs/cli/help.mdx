---
title: "nebula help"
description: "Show help for the CLI or one command"
---

Show help for the CLI or one command.

```bash
nebula help [command] [--json]
```

## Options

| Option | Description |
| --- | --- |
| `--json` | describe every command as JSON (the docs site generates its CLI reference from this) |

## Global options

These work with every command and may appear before or after it.

| Option | Description |
| --- | --- |
| `--project <path>` | run against another Nebula project instead of the current folder |
| `-v, --verbose` | print stack traces and the commands the CLI runs |
| `-y, --yes` | answer every confirmation with yes |
